# 画布插件接入说明（omni-canvas）

> 这份文档说明「技能产出的东西怎么落到画布上、怎么被 H3 消费」。
> 凡是 SKILL.md 没写、但实操会踩的坑，都记在这里。

## 一、音频参考（音色）怎么加

**结论：音频只能走「音频卡」（`type: "audio"`），不能放进图片卡。**

### 正确做法

1. 画布上新建一张**音频卡**（工具栏「音频」，或直接把 `wav/mp3` 拖进画布——上传时按 MIME 自动建成音频卡）。
2. 用**连线**把音频卡连到**视频节点**（连线 = 参考关系）。
3. 提示词里用 `<Audio 1>`、`<Audio 2>` 指定谁在说话。

```
音频卡 A（女声 wav）──┐
音频卡 B（男声 wav）──┴──▶ 视频节点  →  <Audio 1> / <Audio 2>
```

### 插件内部怎么处理（排错时要看）

```
音频卡 n.data.file
  → 上传到 ComfyUI 的 input 目录（voice_xxx.wav）
  → 写进 timeline_data.global.refAudios = [{ audioFile, subfolder:"", type:"input", index }]
  → 提示词没写 <Audio N> 时，自动补 voice_definitions：
       voice_definitions:
       <Audio 1> is the voice of 女声
```

### 硬约束

| 项 | 限制 | 说明 |
|---|---|---|
| 条数 | **最多 3 条** | 超出部分被截断，第 4 条起不生效 |
| 文件格式 | wav / mp3 / m4a / flac | 会被转成 WAV 上传 |
| 连接方向 | 音频卡 → 视频节点 | 反向不生效 |
| 下标 | `<Audio N>` 的 N 从 1 开始 | 越界会提示「提示词引用了 `<Audio 3>`，但只连接了 2 条音色」 |

### 常见错误

| 做法 | 后果 |
|---|---|
| ❌ 把 wav 上传到**图片卡** | H3 把音频当图片解码 → 直接报错（`Could not decode image`） |
| ❌ 音频卡不连线，只在提示词里写 `<Audio 1>` | 没有 refAudios，模型不知道是谁的声音 |
| ❌ 连了 4 条音频 | 只用前 3 条，第 4 条被丢弃（无提示） |
| ❌ 一段里多个角色共用一个 `<Audio N>` | 两个人同一个嗓子（同性别不同角色必须各配一条） |

### 快速自检

提交前问自己三句：

1. 音频卡上 `file` 有值吗？（空卡 = 没上传成功）
2. 音频卡连到这个视频节点了吗？
3. 提示词里的 `<Audio N>` 数量 ≤ 实际连线数吗？

## 二、图片参考与音频参考的区别（最容易混）

| 卡类型 | 进哪条通道 | 提示词引用 | 传错会怎样 |
|---|---|---|---|
| 图片卡 | `refFiles` → H3 参考图槽位 | `<Picture 1>`、`<Picture 2>` | — |
| 音频卡 | `voiceFiles` → `refAudios` | `<Audio 1>` | — |
| 图片卡里放 wav | 仍按图片上传 | 无 | **报错**，音频被当图片解码 |
| 音频卡当参考图连线 | 提交时被自动剔除 | 无 | 音频不参与画面（但仍作为音色） |

> 代码里 `refsOf()` 只收集非音频/非文本卡；`gen.video` 再按扩展名兜底过滤一次。
> 所以「音频卡误连」不会炸，但「wav 放图片卡」会炸——这是唯一需要人注意的地方。

## 三、拼接与成片

- 视频节点按**脚本卡的行顺序**拼接（`cnv_concat`，不传 nodeIds 时自动取）
- 硬切，不做转场；需要转场请在生成时处理
- 成片落回画布为一个视频节点，并写入资产库

## 四、排错入口

| 现象 | 先查 |
|---|---|
| 生成报 `Could not decode image` | 是不是把音频/视频放进了图片卡 |
| 视频没声音 / 声音不对 | 音频卡有没有连线、`<Audio N>` 下标对不对 |
| 画布显示「ComfyUI 未连接」 | ComfyUI 没启动，或启动中（Manager 抓注册表会卡几分钟） |
| 点下载模型没反应 | 模型已就绪（`started=0 skipped=N`）；进度看设置页顶部总进度条 |
