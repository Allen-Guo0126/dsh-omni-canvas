# 资产层：三清单 → 参考图 → 9 图预算

> 目标：用**最少的图**锁住**最多的一致性**。H3 只认图，不认设定表。
>
> **出图工具不限**：本地 ComfyUI、在线生图服务、任何客户端自带的文生图都行（v2.0 起不再绑定某个具体工作流）。
> 下面的提示词模板与版式规则是工具无关的，**照着写就行**。缺图**不阻断下游**，降级为文字档。
>
> **一条取舍**：优先用**纯文生图**（可固定 seed、可复现）。带参考图槽的换装/改脸工作流反而容易把三视图的身份拽跑，
> 真正的锁脸在 H3 端做——三视图就是参考图槽，全片一直挂着（见 §二·补 与 §六）。

## 一、三清单（从剧本抽，不是从想象抽）

### 1.1 角色清单

每个角色一条，只写**可见**：

```
图3 = 沈砚（28岁男，短寸黑发，左眉尾一道旧疤，深灰立领中山装，右腕细银链，身高偏瘦）
```

**必填五项**：年龄段 / 发型发色 / 面部显著标记 / 服装（可换）/ 体型
**不要写**：性格、身世、职业感、气质形容、声音、表情习惯

> H3 会把"气质阴郁"渲染成一张阴沉脸，而不是"有故事的人"。**只写能被画出来的。**

### 1.2 场景清单

```
图1 = 宋府书房（一张主视角：正对空间，能同时看到书案区 / 窗边 / 书架 / 门口）
```

**必填**：空间类型 / 主要固定物（3–5 件）/ 光源位置与性质（窗光/灯光/火光）/ 出入口 / 时代锚（年代/地域风格）/**居住者画像**

**关键**：场景清单要能回答"人站哪"。如果写不出三个可站的位置，这个场景描述还不够。

**居住者画像（2026-11-09 补）**：写清**谁住 / 谁用**，以及这个人的年龄、性别、身份、经济状况。空间的调性必须反映他——
- 二十岁日本留学生租的次卧 ≠ 老城区破屋；应该是**干净、有软装、有生活痕迹**，让观众相信"她愿意住进来"。
- 穷困摄影师的家 ≠ 样板间；旧可以，但要有"他认真生活"的痕迹（洗干净的杯子、叠好的毯子）。

> 只写"老出租屋"三个字，等于把调性交给模型的刻板印象——它默认给你斑驳墙、掉漆柜、昏暗灯。

**时代锚不许默认成"旧"（2026-11-09 补，第三次返工）**：
- **时代锚只能来自剧本原文**。剧本没写年代/新旧，就按**当代**处理——现浇白墙、浅木地板、瓷砖电梯厅、现代家电。
- **"租金便宜"不等于"房子破"**。便宜可以是面积小、位置偏、合租；不能自动推导出"老破小"。
- 角色自嘲台词（如"我这破房子"）是**人物的嘴**，不是**美术设定**。写资产时不要把它当真。
- 当代城市住户外景默认 **电梯 + 过道**，不是楼梯间；只有当剧本明确写"没有电梯/老式楼梯房"时才画楼梯。
- 判据一句话：**这场戏的地址写在剧本里，不写在你的想象里。**

**资产分两级 + 分镜后补差（2026-11-10 新增）**

| 级 | 时机 | 做什么 |
|---|---|---|
| **一级资产** | 剧本定稿后 | 只做**锁身份**的：角色三视图、核心场景、关键道具。数量少、标准高、全片复用 |
| **二级资产** | **分镜定稿后** | 按段反推「资产需求表」，与一级资产求**差集**，补齐缺的 |
| **挂图前检查** | 每段投喂前 | 人 + 景 + 道具是否齐、场景卡的**时间/天气**与本段是否一致 |

> **为什么必须有二级**：一级资产是从「剧本摘要」推的，而分镜是「具体到每镜」的。摘要里没有的东西（一条街、一块松动的砖、一阵雨），分镜会要。
> 真机踩过：剧本前三场都在街上，一级资产只做了「便利店内部」和「夜里的巷口」——**白天的街一张没有**，分镜写到这里只能拿散文补，结果两段渲出两条不同的街。

**场景卡必须带时间/天气标签**：`街边·晨`、`街边·暴雨`、`街边·夜` 是**三张卡**，不是一张。分镜卡的 `sceneTime` 字段要和标签一致，否则就会出现"晨戏挂夜景"。


### 1.3 道具清单

```
图7 = 绣花帕子（月白底，角上一朵褪色红梅，边缘磨毛，巴掌大，可握于掌心）
```

**必填**：材质 / 尺寸（相对人体的参照）/ 颜色纹理 / 状态（新/旧/破损/染血）/ 关键特征（要能被认出来的那一点）/**归属**

**归属（2026-11-09 补）**：这个道具**是谁的**？符合他/她的年龄、性别、身份、地域、经济状况吗？

> 反例（真机踩过）：给二十岁的日本女生配了一只八十年代的手提老皮箱——**形态不对（现在都是拉杆箱）、气质不对（她该是亮色、可爱、有贴纸）**。
> 判据一句话：**把道具放到角色手里，像不像这个人会用的东西？** 不像就重写，别拿"旧物感"当默认审美。

**反光道具注意**：玉佩、银器、镜面类——生图提示词里写"哑光/本色"，**不写光斑、受光、亮起**，否则 H3 会给你一个发光物件。

## 一·补、记忆点（2026-11-10 补：为什么你的角色看起来很普通）

> **病根**：只写「年龄段 / 发型 / 面部标记 / 服装 / 体型」这五项，凑出来的一定是**标准路人**。
> 它们描述的是"这一类人"，不是"这一个人"。

**判据一句话：记忆点 = 一眼认得出、并且想再看一眼的细节。**

> **★ 2026-11-10 修正（第一版写错了）**：第一版把"具体"理解成了"有瑕疵"——疤、痣、断表带、洗不掉的污渍。
> 那些是**降低吸引力**的细节。观众记住一个人，靠的是**好看且有身份**的特征，不是缺陷。
> 同样是"具体"，方向必须朝上：**身材、发型、服装的剪裁、配饰、固定的颜色**。
> **除非瑕疵本身就是剧情信息**（疤是家暴留下的、污渍是加班打翻的咖啡），否则不要往丑里写。

### 1.4 每个角色至少 3 个记忆点（缺一不许出图）

| 位 | 写什么 | 好例子 |
|---|---|---|
| **轮廓** | 身材的可数特征：肩、腰、颈、腿 | 肩宽，腰窄；脖子细长，锁骨明显；手长，指节分明 |
| **发型** | **形状 + 扎法 + 碎发走向** | 低马尾，几缕碎发贴在脸侧；短到能看见头皮的层次，鬓角利落 |
| **服装剪裁** | 款式 + 合不合身 + 材质 + 一颗扣子的开合 | 白衬衫解开最上一颗扣，袖子挽到小臂中段；太合身的针织短袖掐出肩线 |
| **一个配饰** | 小而清，能反复出现 | 只有一只耳的小珍珠耳钉；银色细带表，表盘很小 |

**四样里至少写三样**，且**至少一样是"好看"的来源**（轮廓/剪裁/配饰任选）。

**反面清单（不要当记忆点）**：疤、痣、痘、污渍、破洞、补丁、脱线、断表带、发黄的领口——
除非它承载剧情信息，否则一律不写。**观众不会因为一个人有疤而记住他，会因为他的肩线和一件白衬衫而记住他。**

### 1.5 每个场景至少 3 个记忆点（缺一不许出图）

| 位 | 写什么 | 好例子 |
|---|---|---|
| **一个"贵"的物件** | 说明他的生活水准/审美 | 一把设计感很强的落地灯；一台复古黑胶机；一张真皮单椅 |
| **一处"过分整齐"** | 有人天天在整理 | 书架第三层一排书全部**倒扣**着；鞋柜里的鞋**鞋头朝外，一双不差** |
| **一处"不该出现在这里"** | 暗示别人存在过 / 给伏笔 | 阳台晾衣架上挂着一件**小号女式开衫**；茶几上一只**倒扣的玻璃杯**，下面压着一张旧车票 |

**这三样同时干三件事**：给记忆点、给伏笔、给 H3 一个"必须画出来"的硬指标。

> 场景的"好看"来自**质感和光**，不来自"东西多"。宁可三件有质感的物件，不要十件杂货。


### 1.6 记忆点怎么进提示词

记忆点不写在"主体"那一行里堆着，**单独成行**，因为它要被 H3 逐条复述：

```
[轮廓] 肩宽腰窄，手长指节分明
[发型] 短，鬓角利落，额前一撮不听话地翘起来
[服装] 深灰细针织短袖，合身，掐住肩线；黑色直筒西裤
[配饰] 左手腕银色细带表，表盘很小
```

场景同理：

```
[记忆点] 书架第三层一排书全部倒扣；阳台晾衣架挂一件小号女式开衫；茶几上一只倒扣的玻璃杯压着旧车票
```

> 这些记忆点后续会被直接搬进分镜的「物件镜」和「锚点卡」——**它们不是装饰，是伏笔清单。**

### 1.7 吸引力方向（2026-11-10 补：资产是为"观看欲"服务的）

> **判据：资产图的第一个任务是让人想继续看，第二个任务才是准确。**
> 一张"完全符合设定但没人想看"的资产，等于废图。

**男女主的吸引力方向不同，别用同一套写。**

| | 写什么 | 不写什么 |
|---|---|---|
| **女主** | 可以直接显身材：**腰线收紧**、包臀半裙的贴身线条、腿部线条、锁骨、脖子细长；配饰越少越好（一只耳钉） | 不要写"性感""妩媚"这类词（会渲染成艳俗）；不要过度裸露 |
| **男主** | **松弛、干净、有身材但不刻意**：肩宽、手臂有线条、锁骨在领口处；领军/T恤的肩线正好；头发刚洗过有点乱 | **不要职场感**——不要西装、不要衬衫塞腰、不要领带、不要背头、不要油头 |

**"显身材"的正确写法是写衣服的合身度，不是写身体**：
- ✅ `衬衫下摆收紧进裙腰里，腰线明显` · `短袖肩线正好，不紧身` · `包臀半裙的贴身线条`
- ❌ `身材很好` · `凹凸有致` · `性感`

**一条反差原则**：男女主第一次同框时，**两个人的"用力程度"要不对称**——
一个精心（职业装、高跟、化了淡妆），一个随手（家居裤、赤脚、头发没干）。
**这种不对等本身就是戏**，也解释了"她为什么来找他"。

**收回一条旧规矩**：1.4 的反面清单（疤/痣/污渍/破洞）依然有效，但**还要再加一类：不要为了"接地气"把场景写旧**。
发黄的墙面、老式吸顶灯、堆满杂物的客厅——那是"能住人"，不是"想住进去"。
**现代都市短剧的空间要有品质感**：材质（橡木/岩板/亚麻/哑光黑金属）+ 光（洗墙灯带 / 落地灯 / 窗外城市光），并把"不要昏暗""不要老旧家具"写进禁止项。

## 二、生图提示词模板

### 2.1 角色合成卡（1 张图 = 1 个角色）· 左 1/3 半身大头照 + 右 2/3 无头三视图

**版式：16:9 横构图。左栏占 1/3 放半身大头照（胸像），右栏占 2/3 放正面/侧面/背面三个身体视图，一律自上胸线以下裁切、不画头颈。**

> **为什么右栏去头**（2026-11-09 起，本文件为唯一权威）：三格都画脸时，模型把画力消耗在「三张脸互相对齐」上，三格互相拽脸、服装与廓形细节被挤压。去掉头颈后，右栏变成纯「服装 + 体态」参考——正面给前襟、侧面给外套垂坠与手臂外侧轮廓、背面给后领与后摆结构；脸的真伪只由左栏那张大图负责。
> **提示词默认中文**（2026-11-09 起）；项目显式声明英文提示词语言时才改英文。
> 旧版「右栏三个完整全身像」仍可用，存量卡不返工；新卡一律出无头三视图版。其他技能里凡写「左 1/3 头部特写 + 右 2/3 全身三视图」「单视图 + 三视图两版」的，一律以本节为准。

```
[主体] 28岁东亚男性，短寸黑发，左眉尾一道浅疤，瘦削，深灰立领中山装（棉麻质感，立领扣到顶），右腕细银链
[版式] 16:9 横构图，纯净浅灰背景。左栏占画面宽度 1/3：同一人物的半身大头照，胸像构图，头部、颈肩与上胸完整入镜，正对镜头。
[版式] 右栏占画面宽度 2/3：同一人物的三个身体视图等间距横排，从左到右依次是正面、侧面、背面；三块视图一律从上胸线以下裁切，头部与颈部不入画，只呈现肩线、衣领、袖子、手臂、腰胯、下装与鞋；三块等高、同一套服装：正面看到前襟，侧面看到外套垂坠与手臂外侧轮廓，背面看到后领与后摆结构。
[光线] 柔和自然光，无强阴影
[风格] 写实电影质感，皮肤保留毛孔与细纹，不磨皮
[禁止] 不要文字、不要数字、不要字母、不要分栏线、不要边框、不要水印、不要多余人物、不要夸张表情
```

**要点（2026-11-09 更新，措辞不能改）**
- 必须写 **「左栏占画面宽度 1/3」+「右栏占画面宽度 2/3」**，只写"左边大头照、右边三视图"实测会挤成四宫格
- 左栏必须写 **「胸像构图，头部、颈肩与上胸完整入镜」**
- 右栏必须写 **「从上胸线以下裁切，头部与颈部不入画」**——不写这句，模型照旧画出三个头
- 三视图必须写 **「等间距横排」+「从左到右依次是」+ 每格画什么**；只写"三视图"实测只出两格（正面 + 背面，侧面被吃）
- **写「侧面」，不要写「左侧面」**。"左侧面"会被模型理解成"画面左侧的正面"，还是出正面
- **不要写 FRONT / SIDE / BACK 这类文字标签**——会被烧进画面；零文字靠"不写"，不靠"写了再删"
- **"分栏线"只放禁止项**，不要在版式描述里提；模型容易把"分栏线"当成要画的东西
- 画幅 **16:9**、**2K（2048×1152）** 出图——脸要够像素；1344×768 只用来先看版式
- 一个角色**只出一次**，出了就定版。全片所有段都挂这一张（见 §六）
- **出来的图没有水印，不需要裁底**

### 2.2 场景图（1 张图 = 1 个空间）

**只出一张，正对空间的单一平视主视角。不要九宫格，不要多视角拼图。**

> 这不是省事，是 H3 的能力边界（2026-10-21 定）。给它一张多视角拼图，它认不出哪个是"这个空间"，
> 会自己在正文里补空间——补出来的往往是 H28 那类尺度膨胀（一面墙变成照片展厅）。
> **一张干净的主视角，反而能把"墙上有几件东西、地上有什么"钉死。**

```
[主体] 民国书房，深色木质书案（案上有砚台、毛笔架、一叠信纸），身后顶天书架，右侧木格窗（窗外竹影），左侧屏风
[视角] 正对空间的一个平视主视角，能同时看到书案、书架、木格窗与屏风，四件都不出画
[光线] 右侧窗光为主光，色温 4500K，室内暗部保留细节
[风格] 写实，年代剧质感，木料有使用痕迹
[禁止] 不要文字、不要人物、不要现代物品、不要多格拼图、不要俯视图、不要多个视角
```

**要点**
- 固定物写 **3–5 件，全部单数**（H28：禁 `wall of` / `rows of` / `dzens of`）
- 必须"能同时看到"这几件——这是它跟空间锚点卡对上的唯一方式
- 画幅**跟成片同画幅**：竖屏项目出 `9:16`（约 2.0 百万像素，实测 1088×1856）；横屏项目出 `16:9`
- 一个空间**只出一张**。换景别不换图，靠正文的机位词去切

### 2.3 道具设定图

```
[主体] 月白色绣花帕子，棉质，边缘磨毛，角上一朵褪色红梅（丝线起球），展开约 20cm
[版式] 单件居中，微俯视，右下角一枚硬币作尺寸参照
[光线] 柔光，哑光呈现，无高光反射
[风格] 写实，旧物质感
[禁止] 不要文字、不要手、不要光效
```

## 二·补、出图工具怎么选（工具无关）

### 2.4 选工具的判据

不看牌子，看三条：

| 判据 | 为什么 |
|---|---|
| **纯文生图、能固定 seed** | 可复现。三视图出歪了能微调重来，不会每次换一个人 |
| **能出 2.0 百万像素以上** | H3 取脸靠的是三视图正中那张正面格，脸部像素不够会糊成平均脸 |
| **不出水印 / 不出黄图** | 有水印要裁底，裁多了脸就偏；出黄图整批返工 |

**换来的代价要认**：多数纯文生图**没有参考图槽**，出图端锁不住脸。所以：

- 一个角色**只出一次**三视图，出了就定版，全片不再重出
- 同一个角色**固定 seed**，中途要重出也只改 seed 不换 prompt 骨架
- 真正的锁脸在 H3 端做——那张三视图就是参考图槽，全片一直挂着

> 反过来：如果你的工具带参考图槽（换装/改脸），**不要用它来出三视图**——参考槽会把三视图三格之间的身份互相拽，
> 出成"三个差不多但不一样的人"。要换装就换 prompt 里的服装描述。

[

    "prompt": "16:9 合成卡：左栏占 1/3 头部特写（肩部以下裁掉），右栏占 2/3 正面/侧面/背面三个全身像等间距横排。28岁东亚男性，短寸黑发，左眉尾一道浅疤……" },

|---|---|
| `slot` | **图槽序号**，直接决定落盘文件名，也决定 `<Picture N>` 的编号 |

|---|---|---|

### 2.6 落盘命名与目录（硬规矩）

```
素材库/人物/{槽位号}_{名称}.png     例：人物/1_顾深.png
素材库/场景/{槽位号}_{名称}.png     例：场景/6_凶宅客厅.png
素材库/道具/{槽位号}_{名称}.png     例：道具/9_冥币.png
```

**图按类分开放**：人物 / 场景 / 道具。认不出的一律进 `其他`，不要混进人物里。
一集一套资产时再降一级：`人物/第02集/`。

命名只认**槽位号**——它是唯一和 `<Picture N>` 对得上的东西。

槽位号**两位对齐不补零也行，但必须与 `<Picture N>` 完全一致**。
视频清单里的 `images` 数组按槽位顺序排，第 N 个就是 `<Picture N>`。**命名错了整段白跑。**

### 2.7 出图流程（手工，三句话）

1. 按 §二 模板填 prompt（角色合成卡 / 场景主视角 / 道具设定图），画幅按上表；
2. 一个角色出一个 seed，出到满意即定版，**记下 seed** 写回资产清单；
3. 按 §2.6 直接用**槽位号**命名落盘——不要在事后改名对号，那是错位的主要来源。

## 三、9 图预算表（Ref2VA 核心）

角色资产全量投喂会**瞬间超限**（3View × N 人 + 场景 + 道具 ≫ 9）。按优先级取：

| 优先级 | 取材 | 张数 |
|---|---|---|
| ① | **具体帧锚图**：首帧 / 尾帧 / 构图锚 | 1–2 |
| ② | **主要角色 3View**（每人 1 张板） | 主角 1 + 配角 1–2 |
| ③ | **核心场景**：一张主视角母版（就一张，不出九宫格） | 1 |
| ④ | 对手 / 次要角色 | 1–2 |
| ⑤ | 道具 | 多件**拼一板**算 1 张 |
| ⑥ | 动作/运镜参考视频 | ≤3 段 |
| ⑦ | 音色/BGM 音频 | ≤3 段（必须挂图或视频） |

**典型 15s 双人段 = 3–4 张**
```
图1 主角 3View · 图2 对手 3View · 图3 书房主视角 · 图7 道具（拼板）
= 4 / 9
```

**超限处置**：保 ①②③，其余降级为**文字档**写进 `<Subject N>` 定义行——**不丢信息，只丢"图锁定"强度**。

**铁律**：给了图却在正文一次没提到的 Subject = 白占额度（机检 H5 会抓）。**要么用，要么别投。**

## 四、参考图用途必须标注

每张图在定义行里写清它锁什么：

| 用途 | 写法 |
|---|---|
| 锁形象 | `<Subject 1> is the young woman in Picture 1: …` |
| 锁空间 | `<Subject 3> is the study in Picture 3: a dark wooden desk at the centre, …` |
| 锁道具 | `<Subject 4> is the handkerchief in Picture 4: off-white cotton, …` |
| 锁构图/帧 | `<Picture 2> aligns with the 8.00-second mark; …` |

## 五、M1 / M2 两档交付

### M1（默认，无图也能走）

产出：
1. 三清单（图号 + 一段可见描述）
2. 生图提示词（可直接粘到任何生图工具）
3. **9 图预算表**
4. 《素材接线单》：图号 → 对应 `<Subject N>` → 用途

下游分镜**照常写**，正文用文字档兜住外观（`<Subject 1> is the young woman with black shoulder-length hair, pale skin, a grey linen shirt`）。

**不许因为没图停工**，也不许反过来向用户索图后卡住。

### M2（有图，升级锁）

用户回传图后：
1. 逐张核对是否与三清单一致（不一致以**图**为准，回改清单）
2. 图号 → `<Picture N>` 映射，用途标注
3. 重排 9 图预算
4. 正文里补 `<Picture N>` 引用

## 六、角色一致性三条保命规则

1. **一段至少提一次**：每个在场角色，在 `detailed_description` 里至少被点名一次（H3 会按提到的人渲染，没提到的不生成）
2. **外观只写一次**：定义行写全，正文里只写"她/他"或一个短标记（`the woman in grey`），**不要每镜重复全套外观**——重复会把"描述"当"变化"渲染
3. **服装变化要显式说**：换装必须写"她换上了…"，否则 H3 会按参考图那套给你，或者给你两套混搭

---

## 七、人群调度（群戏别失控）

- **具名上限**：一个 15s 段里**有名字/有外观描述的**角色 ≤3 人
- 第 4 人起必须是"背景人"，写法：`three servants in grey stand along the wall, still`（数量 + 位置 + 状态，不给个体特征）
- **禁**："远处站着个人"（H3 会给你一个模糊鬼影或直接删掉）
- 群戏镜用**全景**交代人数，再用**中近景**给主焦点——不要在中近景里塞五个人
