# 事件分解（分镜前置 · ③-0 / ③-1）

> **为什么有这一步**：剧本写"人物踩到砖，水溅到腿上"，分镜照抄成一镜——生成出来三个动作全糊。
> 病根不在文笔，在**粒度**：一镜里塞了三个"状态变化"。
> 本文件解决的是 **剧本一句话 → 画面几镜** 这一步。它必须发生在"定景别机位"之前。

---

## 一、唯一判据：一镜只允许一个状态变化

**数"了"字。**

> 他踩**到**砖 → 停**住**了 → 水溅**起来**  = 3 个状态变化 = **必须 3 镜**

三个"了"挤进一镜，模型会平均化：踩得不实、停得莫名、水花小得像洒了。

**换个说法**：一镜 = 一个主谓宾。写了第二个动词短语就是超了。

---

## 二、事件先分类：五类，五套拆法

分镜前先问：**这场戏是哪种事件？**

| 型 | 判据 | 靠什么推进 | 身体 |
|---|---|---|---|
| **动作型** | 有事发生（撞/跳/打/摔） | 身体动作 | 会动 |
| **信息型** | 有信息交换（问价/谈判/说明规则） | 数字、评价 | **几乎不动** |
| **物件型** | 靠"看见什么"讲事 | 物件 + 旁白 | 只有日常动作 |
| **关系型** | 两个人说话，关系变化 | 对话 + 一次走位 | 前段不动 |
| **错位型** | 身份/身体/时空错位 | 平行剪辑 | 局部动 |

## 三、五套模板

### A 动作型（范例：她趴出去捡耳机，掉下桥）

```
① 旁人反应 1–3 镜（谁看见了、怎么反应——可以判断错）
② 异常建立 2–3 镜（全景/中景，让人看见"位置")
③ 物件计时 2–6 镜（同一个物件反复给，每次都是"还没拿到"）
④ 身体分解 3–4 镜（接触前 / 接触点 / 脸 / 结果）
⑤ 落点 2–3 镜（结果，全景或特写）
```

**铁律：任何一镜里不许同时出现"动作 + 结果"。**

正例：趴栏杆 → 手伸下去 → 脸（瞳孔放大）→ 腾空。**没有一镜演"她探身去捡"这个完整动作。**

### B 信息型（范例：卖寿命报价）

```
① 定场 1–2 镜（全景 + 招牌/牌匾特写）—— 可以插在中途，不必放开头
② 换嘴切（每句台词一镜，说话人正脸，景别恒定）
③ 每推进一个数字/规则，插 1 个物件镜（屏幕/单据/牌子）
④ 沉默时给对方的低头/手，不给说话人
⑤ 最重要一句：单人、正面、固定、≥3 秒不切
```

**铁律：每镜只有一个信息增量。**

正例："不心疼"这句，**男主不在画面里**——给的是对方双人。最伤的话，不给受害者反应。

### C 物件型（范例：进门看到面）

```
① 人物日常动作 2–3 镜（走 / 推门 / 坐下）—— 全是日常，没有戏剧动作
② 三件物件，各 2–4 镜：俯拍 45°、单物、无手、柔光
③ 每件物件配一句旁白（旁白解释物件，物件证明旁白）
④ 收在人物"回到日常"上
```

**铁律：人不动，物件说话。** 这是最容易 AI 复刻的一类。

### D 关系型（范例：父子吵架）

```
① 固定全景长镜 3–5 秒不切（两人同框，只有一个人说话）
② 正反打（每句一镜，MS ←→ CU）
③ 一次走位打破静态（起身 / 走近），机位跟着变
④ 插入镜承接情绪（墙上的海报 / 桌上的东西）
⑤ 回到全景（新的位置关系）
```

**铁律：走位只给一次，多了就散。**

### E 错位型（范例：身体互换）

```
① 局部特写串联（手 / 眼 / 鞋 / 皮肤），始终不给全身
② 身上一个"可数标记"（数字 / 烙印 / 伤），**反复给 3 次以上**
③ 平行剪辑：两个空间靠同一个标记绑定
④ 对象特写承担情绪（盆 / 杯 / 镜子）
```

**铁律：设定长在身上，不长在台词里。**
正例：手臂皮肤上印着 `00:00:18`。不解释、不旁白、不特效。

## 四、每句台词配一个动作（五级转译）

```
L1 意图      她是在推开他
L2 动作      哪个身体部位、什么幅度、停在哪
L3 反应      对方第一下怎么动
L4 可见事实  能直接写进提示词的那一句
L5 机位      观众站哪才看得见
```

**只写 L1 就出提示词 = 崩。**
写「她拒绝他」→ 模型给你一个"表情不悦的中景"。
写「她右手抬到胸口停住，掌心朝外，没有碰到伞」→ 模型给你一段动作。

**规则：每句台词必须配一个动作，否则这句台词在画面上不存在。**

四问：

| 问 | 答（写进提示词的就是这个） |
|---|---|
| 说话人**哪个部位**在动 | `her right hand rises to chest height` |
| 幅度多少、**停在哪** | `stops, palm out, without touching it` |
| 听话人**第一下**怎么动 | `his arm extends half a hand's width forward` |
| 这句话**谁占上风** | 决定谁给正脸、谁给背影 |

## 五、反例清单（全部来自真实翻车）

| 剧本原句 | 错的分镜写法 | 为什么错 | 改法 |
|---|---|---|---|
| 踩到松动地砖，水溅到腿 | 人物踩到砖，停下，水溅到大腿（1 镜） | 3 个状态变化 | 建立 / 入出画 / 接触点 / 后果 → 4 镜 |
| 从冷柜拿水，拧开看到「谢谢回顾」 | 拿水并看到瓶盖上的字（1 镜） | 信息 + 动作挤一起 | 取水 / 瓶身 / 低头 / 瓶盖特写 / 反应 → 5 镜 |
| 她很伤心地哭了 | 她哭着看向镜头 | 心理结论，没有可见事实 | 给手（握紧又松开）/ 给背 / 给物件 |
| 他震惊地后退 | 他震惊地后退两步 | 情绪词 + 动作同镜 | 脸（瞳孔）+ 脚（后退一步）分两镜 |
| 两人激烈争吵 | 两人争吵（全景 1 镜） | 关系型没有换嘴切 | 全景长镜 + 正反打 + 一次走位 |

## 六、出表后自检（③-1 之后）

逐镜检查四项：

1. **数"了"**：单镜正文里状态变化 ≥2 → 拆
2. **数动词**：单镜里两个以上主谓宾 → 拆
3. **有没有反应镜**：有台词但整段没有"听的人" → 补
4. **最重要那句切没切**：戏核那句如果被切了 → 合并成一个 ≥3 秒的镜

## 七、和现有流程的关系

```
剧本
 → ③-0 事件分解（本文件第二节：这场戏是哪种事件？）
 → ③-1 拆镜（本文件第三节：套对应模板）
 → ③-2 定景别/机位/运镜（原 ③ 的内容）
 → ③·补 表演（四区肌肉）
 → ④ 编译六段式
```

**顺序不能反。** 先定景别再想"这一镜演什么"，就是你之前翻车的原因。
