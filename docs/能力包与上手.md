# 能力包与上手（用户视角）

> 目标：**任何人拿到插件，10 分钟内能出第一张图 / 第一条视频。**
> 缺什么、多大、要不要下载，全部在界面上说清楚，不靠读文档。

## 一、用户拿到插件后的完整路径

```
装插件 → 打开画布 → 上手向导（3 步）
                        ① 确认 ComfyUI 连得上
                        ② 打开「能力中心」看缺什么
                        ③ 开始创作（图片 / 视频 / 分镜）
```

### ① 能力中心（左上「⛁ 能力中心」）

一行一个能力包，显示三种状态：

| 状态 | 界面 | 用户要做的 |
|---|---|---|
| **就绪** | 绿点 +「就绪」 | 什么都不用做 |
| **缺模型** | 黄点 +「缺 N 个模型 · X.XXGB」+ 缺失清单（文件名 / 目录 / 大小） | 点「下载缺失模型」 |
| **缺节点** | 红字「缺少自定义节点：…」 | 按提示装节点（后续可加一键装） |

下载时下方出现进度条：文件名 / 百分比 / 状态（✓ ✗ …），支持**断点续传**，中断后重开继续。

### ② 从现有配置导出能力包

已经在设置里绑好工作流的用户，点「导出当前绑定为能力包」→ 生成
`~/.dsh/omni-canvas.packs/<capability>__<id>.pack.json`，**这个文件就能发给别人**。

### ③ 别人拿到包之后

把 `.pack.json` 放进 `~/.dsh/omni-canvas.packs/` → 打开能力中心 → 看到「缺 N 个模型」→ 一键下载 → 变「就绪」→ 在设置里设为默认实现 → 直接用。

## 二、能力包文件格式（`omni-canvas.pack/1`）

```json
{
  "schema": "omni-canvas.pack/1",
  "id": "image-t2i-94f394",
  "name": "MOSS 全能生图",
  "capability": "image-t2i",
  "workflow": { "file": "moss全能生图.json", "json": { } },
  "inputs": { "prompt": { "node": "65", "field": "text" }, "seed": { "node": "3", "field": "seed" } },
  "outputs": { "image": { "node": "9", "field": "images" } },
  "models": [
    { "file": "moss_image_sft_bf16.safetensors", "dir": "unet",
      "bytes": 10160000000, "sha256": "…",
      "source": { "url": "https://huggingface.co/…/resolve/main/…safetensors" } }
  ],
  "customNodes": [ { "name": "ComfyUI-MOSS", "dir": "ComfyUI-MOSS", "url": "https://github.com/…" } ]
}
```

- `models[].source.url` 是**唯一下载来源**；没有 url 的模型会在下载时提示「缺少下载地址」
- `dir` 决定落到 `ComfyUI/models/<dir>/`
- `sha256` 可选；填了就会校验，不符自动删掉重来

## 三、给打包者（你）的操作

1. 设置里把工作流绑好（已有 4 条：MOSS / Qwen-Image 2.1 / z-image / SeedVR2 4K）
2. 能力中心 →「导出当前绑定为能力包」
3. 打开生成的 JSON，给每个模型补 `source.url`（HF / 魔搭 直链）与可选 `sha256`
4. 把文件发给用户

## 四、翻译引擎（不占显存）

| provider | 说明 | 实测 |
|---|---|---|
| **argos**（默认优先） | 常驻 CPU worker，离线神经 MT，**不占显存、不走 ComfyUI 队列** | 单句 0.06s，600 字 0.79s |
| **dsh**（长文本/高质量） | DSH 默认模型，分段 4 路并行 | 10 段约 8s |
| auto | ≤1200 字走 argos，更长走 dsh | — |

- 语言包位置：`E:\Allen\.tmp\argos-cache\packages`（可用 `OMNI_ARGOS_CACHE` 覆盖）
- 启动时预热（约 2s），之后常驻；`prompt.translate` 返回 `provider/seconds` 便于对比
- 质量：argos 适合"看懂意思"；要精修仍用 dsh

## 五、当前限制（诚实记录）

1. 自定义节点**还不能一键安装**，只做检测与提示
2. `source.url` 需要人工补（模型直链不宜自动猜）
3. 下载并发 2，多个大模型会排队
4. 上手向导只在首次出现（`localStorage.omni.wizard.done`），点「不再提示」后可通过能力中心再进
