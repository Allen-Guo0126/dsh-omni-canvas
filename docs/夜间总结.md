## 二、你现在可以直接用的新功能

### 1. 图生视频（最重要）
画布上：图片节点 → 视频节点（连线）→ 写提示词 → Enter。
实测：底图 480×864，出片 55 秒，首帧确认与底图一致。

### 2. 接一镜（连续镜头一键化）
视频卡片 →「接一镜」→ 自动抽末帧 + 建图片节点 + 建视频节点 + 连好线 + 填提示词。
按 Enter 就出下一镜。

### 3. 语音合成
文本卡片 →「朗读成语音」→ 生成音频节点。
默认中文女声（`zh-CN-XiaoxiaoNeural`），设置页可换「默认音频模型」。
依赖：`node tools/setup.mjs --tts`。

### 4. 胶片条 + 一键拼接
底栏「🎬 镜头 N」→ 按画布顺序排成缩略图条 →「按此顺序拼接」→ 成片落回画布。

### 5. 发布包
视频卡片 →「发布包」→ `~/.dsh/exports/回归成片_480x864_9s.mp4` + 同名说明 txt。

### 6. 平台规格自检
视频卡片自动显示「规格 OK / 规格 N 项」（竖屏、≤60s、≤500MB）。

### 7. 环境自检
设置页顶部：ComfyUI / ffmpeg / edge-tts / 磁盘，缺什么直接给修复命令。

## 三、已修的真问题（原来会出错的）

1. **转换器控件错位**（`widgets_values` 必须先剔除连线字段导致整体错位）
2. **连线被写空**（已连线的控件被覆盖成空串，丢失上游）
3. **动态下拉子输入**必须用带点全名（`format.bit_depth`）
4. **子图未知类型**（子图节点 type 是 uuid，之前当"缺节点"；现按 `-10`/`-20` 展开）
5. **H3 i2v 不认图**（图散落在 segments/shots/keyframes/batchWorkspaces，要整棵树重写）
6. **ffmpeg 判断成功用了分片个数**（`chunks.length` 而非总字节，导致"成功判失败"）
7. **ffmpeg 子进程无写权限**（改为输出 stdout、Node 落盘）
8. **设置页轮询用错状态**（`view` → `page`，之前轮询根本不触发）
