### 现在

```

```

```

场次  场景1·老街 42 | 场景2·客厅 11 | 未归场 61
搜索  提示词 / 镜号 / 场次 / 标签       [★只看收藏]
```

**③ 流程视图（☰）—— 这是你说的"流程性资产面板"**

```
场景1 · 老街（42）
[▷ 缩略图][▷ 缩略图][▷ 缩略图] …   每镜：缩略图 + 镜号 + 时长 + **该镜用到的参考图**
场景2 · 客厅（11）
[▷][▷] …
```

**④ 版本聚合**：同一张卡多次生成 → `v1/18` 角标，点开九宫格选版本（实测樱花项目 78/114 条有版本，单卡最多 18 版）

**⑤ 血缘（⌘）**：父链 → 当前 → 子链

**⑥ 资产详情抽屉（ⓘ）**：大预览 + 提示词全文 + 模型/seed/时间 + 四个动作
`放到画布 / 复制提示词 / 填入当前卡片 / 下载`

**⑦ 拖拽入画布**：从库里拖到画布任意位置，落点即位置（不再固定落中心）

**⑧ 定位（◎）**：点一下跳回这张资产所在的画布卡片
