# 场级双基准与六道门（制作规范 v2）

> 起因（2026-10-31 实测）：
> 1. 同场镜头独立生成导致**光影/色温跳变**（实测场内亮度极差最高 72.1，暖度极差 38.6）
> 2. 说话人未登记 + 编号塌陷导致**声音错配**（教室场「期末要考」用了学生声线）
>
> 本规范用来在流程里把这两类问题挡住，而不是靠后期救。

## 0. 量化目标

| 指标 | 定义 | 现状最差 | 目标 |
|---|---|---|---|
| 场内容量极差 | 同场各镜平均亮度 max−min | 72.1 | ≤ 12 |
| 场内容温极差 | 同场各镜 (R−B) max−min | 38.6 | ≤ 10 |
| 台词缺字率 | 听审判定缺字/吞字的镜头占比 | 未知 | 0 |
| 说话人错配 | 声线与声音基准不符的镜头数 | 5/19 | 0 |

---

## 1. 场级视觉基准（G1）

每场**必须**先写一段参数化基准，再写镜头。禁止只写形容词。

```text
【场级视觉基准】场 5 · 街边夜
色温：主光 2700K（钠灯）/ 环境 8000K
主光方向：画面右侧 45° 低位
曝光目标：平均亮度 50–65
参考板：街边夜板（唯一）
白平衡锁：4200K 固定，禁止自动白平衡
镜数上限：≤ 4（超过必须合并成 12–15s 长镜）
```

规则：
1. **一场一板**：同一场所有镜头只能引用同一张场景板；引用多张 → G1 不通过
2. 场景锁文本**逐字一致**地注入同场每条 prompt（不是改写）
3. 提升词里**禁用相对色词**：暖黄、冷白、明亮、昏暗、通透、阴森
   → 只能写 K 值、方向、亮度区间
4. 曝光目标给区间，不给单值（避免锁死）

## 2. 场级声音基准（G5）

每场列出本场所有发声者，编号固定，画外单独标。

```text
【场级声音基准】场 2 · 教室
S1 = 王三合｜25 岁男声｜偏沉、语速中等｜画内
S2 = 学生  ｜17 岁男声｜偏亮、含糊、有气无力｜画外（不入画）
S3 = 老张  ｜52 岁男声｜粗而亮、带笑腔｜画内
禁止：任何未登记的声音；一句台词只能归属一个 S 编号
```

规则：
1. **每个说话人都必须有定义**（包括群众、广播、旁白），没有定义 = 不许出声
2. **画外声必须标"画外（不入画）"**，并与画面人物的口型解耦
3. **同性角色必须写音色差异**（younger/lighter vs older/lower/slower），否则模型会混
4. 群杂声二选一：
   - 建 S 编号（可控，但占用声部）
   - 统一写"画外群杂，无具体人声"（省声部）
5. 旁白（VO）/广播/电话必须独立编号，**不得借用画面人物声部**

## 3. 分镜表新增两列（必填）

| 列 | 规则 | 示例 |
|---|---|---|
| **说话人** | 每条台词必填；画外标注 | `S1 王三合` / `S2 学生(画外)` / `S3 广播(画外)` |
| **台词预算** | 自动算：`ceil(字数/4.5)+2` 秒（保守）或 `ceil(字数/5.0)+1.2`（激进） | 「期末要考。5 字 → 4s」 |

预算 > 镜长−0.5 → 该镜不许过门（C3）。

## 4. 提示词编译模板（固定结构，人只填镜头段）

```text
subject_definitions:
<Subject 1> is <角色>（外形/服装/参考图编号）｜声音：<年龄性别、音色、语速>｜<画内/画外>
<Subject 2> is <角色>｜声音：…｜画外（不入画）
<Subject 3> is <场景>（唯一场景板）
[视觉锁] All shots in this scene share: <色温/主光方向/曝光区间>；固定白平衡；同一场景板。
[声音规则] Each spoken line belongs to exactly ONE subject. All other subjects keep
          their lips CLOSED with no lip-sync. Off-screen subjects never appear in frame.

detailed_description:
<逐段：秒数 → 景别/机位/焦段 → 朝向 → 起→唯一动作→终 → 切点>
<台词按说话人逐个标注，编号必须与声音基准一致>

overall_soundscape: <环境声 + 人声清单（谁说了哪句）>
non_diegetic_music: N/A
```

## 5. 六道门

| 门 | 时机 | 判定 | 失败处理 |
|---|---|---|---|
| **G1 视觉基准** | 写分镜时 | 每场有【场级视觉基准】且一场一板 | 补齐才能进下一步 |
| **G5 声音基准** | 写分镜时 | 每场有【场级声音基准】，覆盖所有发声者 | 补齐 |
| **G6 台词归属** | 编译提示词时（自动） | C1 归属可解析 / C2 说话人有定义 / C3 预算够 | **报错，不提交生成** |
| **G3 锚点门** | 每场第一条生成后 | 人工确认（光、声、口型） | 确认后才批量出同场其余 |
| **G4 一致性门** | 每条生成后（自动） | 亮度偏差 ≤12、暖度偏差 ≤10 | 回炉 |
| **G7 听审门** | 每条生成后（人工） | 台词不缺字 / 说话人对 / 非说话人闭嘴 | 按阶梯回炉 |

### 编译期三道校验（G6）

| 校验 | 规则 |
|---|---|
| C1 归属 | 每句台词必须解析出唯一说话人；0 个或多个 → 报错 |
| C2 定义 | 说话人必须在 `subject_definitions` 中有条目（含画外） |
| C3 预算 | `字数/4.5+2 ≤ 镜长−0.5` |

### 回炉阶梯（固定顺序，不许跳）

1. 换首帧（同场锚点镜尾帧）→ i2v 重出
2. 加锁（视觉锁逐字补齐 / 声音编号修正 / 音色差异补写）
3. 合并（两镜并一镜 12–15s，减少一次采样）
4. 仍不合格 → 标记该镜为"待人工"，继续下一镜（不阻塞全片）

## 6. 生成调度规范（配合 G3）

| 规则 | 说明 |
|---|---|
| 锚点镜优先 | 每场先出最长/最全的一条（r2v + 唯一场景板 + 双锁） |
| 尾帧链优先 | 同机位后续镜用前一镜尾帧当首帧（i2v），光与场景被物理锁定 |
| 反打例外 | OTS 机位变化不能复用首帧 → 仍用双锁重采样，且必须在锚点镜之后 |
| 同场镜数 ≤4 | 超过则合并 |
