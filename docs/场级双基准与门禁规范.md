# 场级双基准与六道门（制作规范 v2）

> 起因（2026-10-31 实测）：
> 1. 同场镜头独立生成导致**光影/色温跳变**（实测场内亮度极差最高 72.1，暖度极差 38.6）
> 2. 说话人未登记 + 编号塌陷导致**声音错配**（教室场「期末要考」用了学生声线）
>
> 本规范用来在流程里把这两类问题挡住，而不是靠后期救。

## 0. 量化目标

| 指标 | 定义 | 现状最差 | 目标 |
|---|---|---|---|
| 场内容量极差 | 同场各镜平均亮度 max−min | 72.1 | ≤ 12 |
| 场内容温极差 | 同场各镜 (R−B) max−min | 38.6 | ≤ 10 |
| 台词缺字率 | 听审判定缺字/吞字的镜头占比 | 未知 | 0 |
| 说话人错配 | 声线与声音基准不符的镜头数 | 5/19 | 0 |

---

## 1. 场级视觉基准（G1）

每场**必须**先写一段参数化基准，再写镜头。禁止只写形容词。

```text
【场级视觉基准】场 5 · 街边夜
色温：主光 2700K（钠灯）/ 环境 8000K
主光方向：画面右侧 45° 低位
曝光目标：平均亮度 50–65
参考板：街边夜板（唯一）
白平衡锁：4200K 固定，禁止自动白平衡
镜数上限：≤ 4（超过必须合并成 12–15s 长镜）
```

规则：
1. **一场一板**：同一场所有镜头只能引用同一张场景板；引用多张 → G1 不通过
2. 场景锁文本**逐字一致**地注入同场每条 prompt（不是改写）
3. 提升词里**禁用相对色词**：暖黄、冷白、明亮、昏暗、通透、阴森
   → 只能写 K 值、方向、亮度区间
4. 曝光目标给区间，不给单值（避免锁死）

## 2. 场级声音基准（G5）

每场列出本场所有发声者，编号固定，画外单独标。

```text
【场级声音基准】场 2 · 教室
S1 = 王三合｜25 岁男声｜偏沉、语速中等｜画内
S2 = 学生  ｜17 岁男声｜偏亮、含糊、有气无力｜画外（不入画）
S3 = 老张  ｜52 岁男声｜粗而亮、带笑腔｜画内
禁止：任何未登记的声音；一句台词只能归属一个 S 编号
```

规则：
1. **每个说话人都必须有定义**（包括群众、广播、旁白），没有定义 = 不许出声
2. **画外声必须标"画外（不入画）"**，并与画面人物的口型解耦
3. **同性角色必须写音色差异**（younger/lighter vs older/lower/slower），否则模型会混
4. 群杂声二选一：
   - 建 S 编号（可控，但占用声部）
   - 统一写"画外群杂，无具体人声"（省声部）
5. 旁白（VO）/广播/电话必须独立编号，**不得借用画面人物声部**

## 3. 分镜表新增两列（必填）

| 列 | 规则 | 示例 |
|---|---|---|
| **说话人** | 每条台词必填；画外标注 | `S1 王三合` / `S2 学生(画外)` / `S3 广播(画外)` |
| **台词预算** | 自动算：`ceil(字数/4.5)+2` 秒（保守）或 `ceil(字数/5.0)+1.2`（激进） | 「期末要考。5 字 → 4s」 |

预算 > 镜长−0.5 → 该镜不许过门（C3）。

## 4. 提示词编译模板（固定结构，人只填镜头段）

```text
subject_definitions:
<Subject 1> is <角色>（外形/服装/参考图编号）｜声音：<年龄性别、音色、语速>｜<画内/画外>
<Subject 2> is <角色>｜声音：…｜画外（不入画）
<Subject 3> is <场景>（唯一场景板）
[视觉锁] All shots in this scene share: <色温/主光方向/曝光区间>；固定白平衡；同一场景板。
[声音规则] Each spoken line belongs to exactly ONE subject. All other subjects keep
          their lips CLOSED with no lip-sync. Off-screen subjects never appear in frame.

detailed_description:
<逐段：秒数 → 景别/机位/焦段 → 朝向 → 起→唯一动作→终 → 切点>
<台词按说话人逐个标注，编号必须与声音基准一致>

overall_soundscape: <环境声 + 人声清单（谁说了哪句）>
non_diegetic_music: N/A
```

## 5. 六道门

| 门 | 时机 | 判定 | 失败处理 |
|---|---|---|---|
| **G1 视觉基准** | 写分镜时 | 每场有【场级视觉基准】且一场一板 | 补齐才能进下一步 |
| **G5 声音基准** | 写分镜时 | 每场有【场级声音基准】，覆盖所有发声者 | 补齐 |
| **G6 台词归属** | 编译提示词时（自动） | C1 归属可解析 / C2 说话人有定义 / C3 预算够 | **报错，不提交生成** |
| **G3 锚点门** | 每场第一条生成后 | 人工确认（光、声、口型） | 确认后才批量出同场其余 |
| **G4 一致性门** | 每条生成后（自动） | 亮度偏差 ≤12、暖度偏差 ≤10 | 回炉 |
| **G7 听审门** | 每条生成后（人工） | 台词不缺字 / 说话人对 / 非说话人闭嘴 | 按阶梯回炉 |

### 编译期三道校验（G6）

| 校验 | 规则 |
|---|---|
| C1 归属 | 每句台词必须解析出唯一说话人；0 个或多个 → 报错 |
| C2 定义 | 说话人必须在 `subject_definitions` 中有条目（含画外） |
| C3 预算 | `字数/4.5+2 ≤ 镜长−0.5` |

### 回炉阶梯（固定顺序，不许跳）

1. 换首帧（同场锚点镜尾帧）→ i2v 重出
2. 加锁（视觉锁逐字补齐 / 声音编号修正 / 音色差异补写）
3. 合并（两镜并一镜 12–15s，减少一次采样）
4. 仍不合格 → 标记该镜为"待人工"，继续下一镜（不阻塞全片）

## 6. 生成调度规范（配合 G3）

| 规则 | 说明 |
|---|---|
| 锚点镜优先 | 每场先出最长/最全的一条（r2v + 唯一场景板 + 双锁） |
| 尾帧链优先 | 同机位后续镜用前一镜尾帧当首帧（i2v），光与场景被物理锁定 |
| 反打例外 | OTS 机位变化不能复用首帧 → 仍用双锁重采样，且必须在锚点镜之后 |
| 同场镜数 ≤4 | 超过则合并 |

## 8. 提示词编译的三类锁（2026-11-01 实测补充）

生成 EP1 时踩到三个坑，全部来自"指令写错位置"，不是模型不行。

### 8.1 文字锁（关字幕）

**现象**：H3 会把台词当字幕烧进画面，还带英文副标题，甚至出现错字（「还挺与时俱进」→「还真与时俱进」）。工作流里**没有**字幕开关，只能靠提示词压。

**写法**（每段都要，逐字一致）：

```text
NO ON-SCREEN TEXT OF ANY KIND: no subtitles, no captions, no caption bar,
no lower-third, no letters, no Chinese characters, no English words,
no watermarks, no logos. Dialogue is only heard on the audio track and is
never rendered as visible text anywhere in the frame.
```

**实测**：加这段后字幕消失（1/1 有效）。

### 8.2 主体锁（人物描述必须绑 Subject 编号）

**现象**：把「老道是灰白短发不是光头」写成**全局句**后，模型把这句套到**主角**身上 —— 王三合变成灰白发、白衬衫打领带，脸都不像了；老道照样秃。

**规则**：
1. 任何人物级描述（发型/服装/年龄/表演）**必须**写成 `<Subject N> is ... . <锁>`，N 用该镜实际的编号
2. **禁止**出现"the Taoist has ...""all characters ..."这类不绑编号的句子
3. 同一镜里两个同性别角色，锁要写**互斥特征**（黑短发 vs 灰白短发；开衫 vs 道袍）
4. 编译后自检：每条人物锁句必须能在同段找到 `<Subject N>` 前缀，找不到 → 报错

### 8.3 表演锁（表演方向也绑主体）

**现象**：剧本写"干笑、笑不下去"，模型演成"开心大笑"（D5 段）。

**规则**：表演方向写成 `<Subject N> 动作描述 + 否证`，例如：

```text
(Subject 1) forces a grin that dies halfway — the smile freezes at its peak
then collapses; he is NOT laughing happily.
```

否证句（NOT ...）比正向描述更有效。

### 8.4 台词文本清洗

编译时要去掉所有"（22 字／4.0 = 5.5s）""→ 38 字"这类预算注记，否则会漏进 `<d>[...]</d>` 被念出来或显示成字幕。

### 8.5 三条锁的落地位置

| 锁 | 作用域 | 编译阶段 |
|---|---|---|
| 文字锁 | 每段 | 全局常量，逐字注入 |
| 主体锁 | 每段、每个出场人物 | 按参考图连线生成 Subject 编号后绑定 |
| 表演锁 | 有特殊表演要求的段 | 分镜表新增 `acting` 字段，编译时绑到对应 Subject |

## 9. G0 集容量门（立项时，写分镜之前）

**问题**：先定"单集 130 秒"，再把 454 字台词塞进去 → 语速 6–7 字/秒、单镜 2.3–3.0 秒，观众看不出在讲什么。

**算法**：

```
need = 台词字数 / 4.0            (正常中文语速)
     + 0.5s × 台词句数           (句读呼吸)
     + 3.5s × 场数               (空间交代)
     + 8s                        (片头片尾/留白)

need > 目标时长 → 三选一，必须显式决定：
  a) 延长到 need（不删内容）
  b) 删减，并列出删减清单（删什么/为什么/省几秒）
  c) 拆集

禁止：既定死时长上限、又要求"台词零删改"（互斥约束，编译前直接报错 = G9）
```

实测：EP1 原稿 454 字台词 → need ≈ 161 秒；被压进 133 秒后，16/19 段语速 >4 字/秒。

## 10. G8 叙事清晰度门

| 规则 | 阈值 |
|---|---|
| 单刀（每个机位）时长 | ≥ 3.0s，建议 3.5–5.0s |
| 语速 | ≤ 4.0 字/秒（VO ≤ 4.5） |
| 每段刀数 | ≤ 2 |
| 每段台词句数 | ≤ 2 |
| 同段空间 | 不跨空间（教室/走廊=两块） |
| 段长 | 8–12s 为主；≤5s 仅允许"纯反应/纯转场" |
| 每段叙事功能 | 只承担 1 个（交代/动作/台词/反应/转场） |

## 11. G9 指令一致性门

编译前检查：同一份任务说明里是否同时存在

- "时长上限 = X 秒"
- "台词一字不改 / 不得删改"

两条同时出现 = 互斥，**拒绝编译**，要求先走 G0 三选一。

## 12. 同场景合并规则（切片算法）

```
按"同一时空块"分组（如：道观内殿 / 大街上 / 考场）
块内从第一镜开始累加：
  累计时长 ≤ 15.0s 且 累计台词预算 ≤ 累计时长−0.5 → 继续并
  再并会超 15.0s → 收段，另起一段
输出段数；任一块段数 > 4 → 报错，人工指定
```

效果：EP1 由 19 段并到 13 段（少 6 次独立采样），总时长不变、叙事密度下降。
