# 短剧制作规范 v3（单一真相源）

> 本文件是**制作规则与门禁的唯一真相源**。
> - H3 提示词的**字段结构与英文句式** → 见 skill `h3-prompt-writing`（本文件只链接，不复述）
> - 分镜的**创作动作** → 见 skill `short-drama-storyboard`（本文件只管门槛与判定）
> - 逐项勾选表 → 见 `docs/提示词审查清单.md`（G13 的执行清单）

## 0. 变更与废弃机制

规则只增不改会导致新旧并存。**每次修改必须做三件事**：

1. 在 §18 CHANGELOG 记一行：日期 / 改了什么 / 取代了哪条
2. 被取代的条文**直接删除**，不留在正文里
3. 若某条被推翻但删除会影响理解，写一句「不得再写 X（2026-11 起，见 §7.3）」放进 §7.3

**禁止**：在文件末尾追加新章节而不处理旧章节——v1–v2 的重复与冲突全部源于此。

## 2. G0 集容量门（立项时）

```
need = 台词字数 / 4.0 + 0.5 × 句数 + 3.5 × 场数 + 8
```

`need > 目标时长` → 三选一，并在创作简报里写明选了哪个：
a) 延长到 need ｜ b) 删减（产出删减清单：删什么/为什么/省几秒）｜ c) 拆集

**禁止**同时写「时长上限」与「台词零删改」（互斥，G0 直接拦截）。

实测：EP1 原稿 454 字台词 → need ≈ 161 秒；压进 133 秒后 16/19 段语速 >4 字/秒。

---

## 3. G1 视觉基准（一场一条，极简）

**只写一句**，不写数值：

```text
光照、时间、色温、灯态都沿用场景图（<Picture N>）；人脸始终可辨。
```

- **不写**色温 K 值、亮度区间、光比、主光方向——模型不读，还会覆盖场景图
- **不写**「近乎全黑 / 天光已退 / 只剩剪影 / 纯黑 / 压暗」
- **例外**：光有状态变化时（路灯由灭转亮、烛火爆灭），变化点单独写一句，并指定在哪一刀发生
- 一场**只用一张场景板**；同场跨时段 → 换板或换场次，不许一板两用

实测反例：场4 曾写「天光已退、背景近乎全黑」→ 整段压成深夜，与场3 断崖。

## 4. G2 声音基准（一场一张 S 表）

```text
S1 = 王三合｜25 岁男声，平、偏沉｜画内
S2 = 老道  ｜65 岁男声，低、慢｜画内
S3 = 学生  ｜17 岁男声，偏亮含糊｜画外，不入画
```

1. 每个发声者都必须登记（含群众、广播、旁白）；未登记 = 不许出声
2. 画外声标「画外，不入画」
3. 同性角色必须写音色差异（younger/lighter vs older/lower/slower）
4. 旁白 / 广播 / 电话独立编号，不占用画面人物声部

## 5. G3 台词窗口（每刀）

```
可用说话时长 = 刀长 − 0.4（前置动作，≤0.4s） − 0.3（收尾留白）
要求：汉字数 / 4.0 + 0.5 × 句数 ≤ 可用说话时长
```

- 动作只有两种：**≤0.4s 的前置动作**，或**与台词并行**（`as he speaks`）
- **禁止**「做完动作再开口」——模型会吃掉台词
- 跨刀台词：两刀都写 `<scenetrans>`，后刀写 `continues the same sentence without pause`

## 6. G4 覆盖变化 / G5 机位理由

### 6.1 机位六选（不是模板，是判断）

`master-2` / `single-A|B` / `OTS-A|B` / `profile-2` / `insert` / `empty`

### 6.2 逐刀六问（答案写进该刀的机位理由，一句话）

1. 这一刀让观众得到什么？（信息 / 情绪 / 关系 / 空间）
2. 有没有**表情落点**（僵住、笑僵、眼神变）？→ 有就给脸（`single`）
3. 需要交代距离或人数？→ `master-2`
4. 要表现压制/逼近？→ 过肩，且**前景＝被压的一方、零表演**
5. 要藏剪辑或点题物？→ `insert`
6. 风险高吗（复制人 / 空间漂移 / 口型）？→ 高就别用过肩

优先级：**表情落点 > 关系交代 > 压迫感 > 留白**

### 6.3 防单调

| 约束 | 阈值 |
|---|---|
| 同机位连续 | ≤2 刀 |
| ≥3 刀的段 | 至少 2 种机位 |
| 过肩占比 | ≤1/3 |
| 单刀时长 | ≤6s 无需解释；>6s 写「为什么不能切」 |
| 机位理由 | 每刀必填 |

### 6.4 调度写「关系」不写「位置」

| 场景 | 正确调度 |
|---|---|
| 喊人 / 拦住 / 追人 | 被喊的人**背对或侧对**对方往前走；对方转向他的背影喊；他停步、回头、半转身 |
| 对峙 | 两人正对（侧面 90° 或各偏 45°） |
| 说服 | 一方侧对、一方正对（权力差） |

**禁止**「两人面对面站着喊请留步」（逻辑反了）。

## 7. 提示词体例（极简）

### 7.1 图即描述

- `<Subject N> = <Picture N>（谁，三视图）`，一句「身份、发型、服装、配饰完全照它」
- 场景 / 道具同理：`<Picture M> 是场景图，空间、陈设、光线完全照它`
- 光：一句（见 §3）
- 站位：一句关系句（见 §6.4）

### 7.2 G10 长度

| 项 | 上限 |
|---|---|
| 每段提示词 | 900–1400 字符（>2000 说明在重述图片） |
| subject_definitions | ≤3 行 |
| 每刀 visual | 30–50 词 |

### 7.3 不得再写（2026-11 起）

| 禁止 | 取代为 |
|---|---|
| 色温 K 值 / 亮度区间 / 光比 / 主光方向 | §3 一句「照场景图」 |
| 「卡面灰底 / 棚拍光 / 多视图不进入画面」 | 删（靠取景解决） |
| 「同一个人只出现一个身体」 | 删（靠机位：单人/过肩/插入） |
| 每刀复述背景方位 | 只在换机位处写一句「还是同一个街角」 |
| 把数字当约束（45–58 亮度、4200K） | 删 |

### 7.4 G9 排除句白名单（必须写的）

| 场景 | 必须写 |
|---|---|
| 画外说话 | 画面里不许有正脸人物；该人物 `lips remain completely closed` |
| 过肩镜头 | 前景人物 `no expression, mouth completely closed, no gesture, no speech` |
| 画外人物 | `not in frame at all — not even a shoulder or a shadow` |

（英文句式见 `h3-prompt-writing`）

## 8. G6 说话人可见

**谁说话，谁必须在画面里开口。**

| 情况 | 允许 |
|---|---|
| 说话人在画面内 | ✅ |
| 说话人在画外 + 画面里有正脸人物 | ❌ 模型会把台词判给画面里的人 |
| 说话人在画外 + 画面是插入镜/空镜/后脑 | ✅ |

编译检查：台词标注的 S 编号，必须在该刀 visual 里出现对应人物名。

实测：D4 后半句「听的人单人 + 老道画外」→ 成片变成王三合在说。

---

## 9. G7 朝向（≥2 人的镜头）

必写三句：

```
face each other / bodies angled about 45 degrees to the lens / neither looks into the lens
```

- 单人镜写「朝向画外的对手」，**不许**写 `facing the lens`
- 编译检查：双人镜缺任一句 → 报错

实测：C1/C3 旧版只写「A 在画左、B 在画右」→ 两人面对镜头。

---

## 10. G8 动作连贯（矛盾自检）

同一刀内的动作必须连得起来，**终点在画面内**（除非该刀结束）。

| 禁止组合 | 冲突点 |
|---|---|
| 「正走出画面」+「停下/回头/转身」 | 出画后不能有动作 |
| 「背对镜头」+「表情」 | 看不到脸 |
| 「已坐下」+「站起身」（同一刀） | 时间不够 |
| 「说完转身走」+「继续说话」 | 位置与声音冲突 |
| 「画外说话」+「画面里有正脸人物」 | 见 §8 |
| 「灯未亮」+「灯光洒在他脸上」 | 灯态冲突 |

写法：**起点状态 → 触发 → 终点状态**。

实测：C1 写「walking out of frame」+「he stops and turns」→ 走了又回来。

## 11. G11 一致性测量（每条生成后）

测每条片段第 1 秒的画面：平均亮度、R−B 暖度。

| 指标 | 阈值 |
|---|---|
| 场内亮度极差 | ≤12 |
| 场内暖度极差 | ≤10 |

超阈值处理阶梯：
1. 换首帧（同场前一刀尾帧，i2v）重出
2. 加锁重出（光/朝向/说话人）
3. 段级轻校正（封顶 ±12% 亮度、±12% 通道）——只做收尾，不替代生成
4. 标记「待人工」，继续下一刀，不阻塞全片

实测 v4：场2 2.4/1.6 ✅、场3 9.4/5.1 ✅、场4 5.3/7.6 ✅、场1 8.1/11.4 ⚠️

## 12. G12 段容器与故事板先行（2026-11-02 升级，硬门）

### 12.1 容器制（取代"每刀独立生成"）

- **Segment ≤15s 是唯一生成单元**，段内装 2–5 个 beat，模型在段内自己完成推拉与软切
- 硬切只发生在段缝；90s 的集 ≈ 6 段，不是 16 刀
- 上一段尾帧可作下一段首帧（尾帧链，i2v）

### 12.2 故事板先行门

每段先出一张 16:9 四宫格故事板（CLEAN_GRID：零文字、零格号、零箭头），**接受后才许生成该段视频**。

### 12.3 为什么（2026-11-01 A/B 实测结论）

| 实测 | 结果 |
|---|---|
| A 版：16 刀独立生成 | 每刀一张"证件照"，动作刻意，穿帮 16 个缝 |
| B 版：6 段长镜（每段内 4–5 beat） | 空间连续、表演连贯，仅段缝 5 个 |

长镜能稳的前提是故事板先行；没有板的 15s 生成风险大，所以两步必须绑在一起。

### 12.4 同场刀数（旧规则废止）

「同场 ≤4 刀、超过合并」的旧写法由本节容器制取代：刀数不再是生成次数，段数才是。

## 13. G13 批次审查（强制）

任何一批提示词在提交生成前，必须过一遍独立审查，用 `docs/提示词审查清单.md` 十组逐条勾选。

**不通过 = 不许生成。** 审查结果归档到画布「审查报告」卡。
审查者不能是写这批提示词的人（人或另一 agent 均可）。

---

## 14. 字幕策略（交付决定）

**本片：画面无字幕。**

- 提示词写「NO ON-SCREEN TEXT OF ANY KIND」否证句
- 台词靠声音；字幕若需要，后期另做（不在生成里烧）
- H3 会主动把台词烧成字幕，必须每次显式否证

---

## 15. 台词唯一真相源

- 剧本卡里的**台词行**是唯一真相源；其余文档只引用不复述
- 分镜里的台词必须从剧本复制，不许改写、不许加注记
- 修改台词 → 先改剧本卡 → 再同步分镜 → 再重编提示词

## 19. 群体镜头（G7 扩展）

### 19.1 三条必写

群体镜（≥3 人）必须在提示词里写清：

1. **机位在空间的哪一端** —— `the camera stands at the back of the room looking forward`
2. **观众看到的是正面还是背面** —— `what fills the frame is the backs of heads and shoulders; no face is visible`
3. **群体朝向与机位是否自洽** —— 见 19.2

### 19.2 机位必须与「要表现的内容」匹配

| 观众要看到 | 机位必须 | 不能写 |
|---|---|---|
| 主角背影、全场安静 | 教室**后方** | 不许要求群体表情 |
| 群体崩溃、有人哭 | 教室**讲台**（学生朝镜头＝朝黑板） | 不许要求主角背对且露脸 |
| 两者都要 | **拆两刀**：先背后机位、再讲台机位 | 不许塞进同一刀 |

**冲突范例（EP2 实际踩过）**：后方机位 + “学生抽泣/抹眼泪” → 模型把整排学生转向镜头，主角与群演错位。

### 19.3 群演不给角色卡

- 参考图只给**主角卡 + 场景板**；群演用文字（`forty anonymous students in school uniform`）
- 给群演角色卡会把“可识别的正脸”带进画面，模型优先让人露脸

### 19.4 座位/站位写坐标，不写序数

```
He sits in the third row from the front, second seat from the window side; the two seats
beside him are empty and the rows ahead of him are full.
```

（只写“第三排”模型无法落位，人与桌椅会错位。）

### 19.5 用前景压住“露脸冲动”

```
The nearest row of heads and shoulders fills the lower third of frame, soft and out of focus;
beyond them the desks recede toward the blackboard.
```

## 20. 分工与产出契约（2026-11 起强制）

### 20.1 谁做什么

| 环节 | 负责 | 不许 |
|---|---|---|
| 剧本 | 子 Agent（独立上下文） | 主 Agent 不得自行改编 |
| 分镜 | 子 Agent（输入：剧本 + 规范摘要；输出：分镜 JSON） | 主 Agent 不得自行拆分镜 |
| 提示词 | 子 Agent（输入：**只有分镜 JSON**；输出：按模板渲染的提示词） | **不得手写**；主 Agent 不写 |
| 审查 | 另一个子 Agent（不知道谁写的） | 写的人不得审自己的稿 |
| 校验 / 生成 / 拼接 | **主 Agent** | 主 Agent 不再参与创作 |

### 20.2 为什么

- 主 Agent 上下文里堆了返工史，拆分会不自觉沿用上集结构（EP2 第 7/8 段重复 EP1 结尾即为此）
- 自写自审等于没审
- 手写提示词会漏字段（朝向、说话人、预算），无法机械校验

### 20.3 契约

分镜必须以 **JSON** 交付，字段见 `docs/分镜JSON契约.md`；提示词由该 JSON + 固定模板渲染，
模板由主 Agent 持有，子 Agent 不得改句式。

### 20.4 主 Agent 的校验清单（收到 JSON 后）

1. JSON 字段完整（缺字段 = 退回，不进入渲染）
2. G3 台词窗口、G7 朝向/群体、G8 动作链、G6 说话人可见、G10 长度
3. 渲染后抽查 2 段，与 JSON 逐字比对（防渲染器漂移）
