# P1 + P2：本地 ComfyUI 探测/启动 + 工作流发现

## P1 · 本地 ComfyUI

### API

| API | 说明 |
|---|---|
| `comfy.find` | 并发探测端口 + 扫盘找安装，返回 `{ running[], installs[], savedInstallPath, launchedByPlugin }` |
| `comfy.start` | 用 `{path}` 启动；已有实例在跑则直接返回 `{already:true}`，不会起第二个 |
| `comfy.stop` | 只杀**插件自己启动**的进程（`taskkill /PID /T /F`） |

### 探测顺序

1. `~/.dsh/comfy-canvas.settings.json` 里的 `installPath`（上次成功的）
2. 常见目录：`%USERPROFILE%\ComfyUI`、`Documents/ComfyUI`、`Desktop/ComfyUI`、`C/D/E/F:\ComfyUI`
3. 各盘根目录下名字含 `comfy` 的目录
4. 校验：存在 `main.py` 才算（顺便统计 `custom_nodes` 数量、`models` 是否存在）

### 启动方式识别（按优先级）

```
<dir>/python/python.exe -s main.py          ← 整合包（如 E:\ComfyUI-aki-new）
<dir>/venv/Scripts/python.exe -s main.py
<dir>/.venv/Scripts/python.exe -s main.py
<dir>/python_embeded/python.exe -s main.py
<dir>/run_nvidia_gpu.bat | run.bat | run_cpu.bat | run_amd_gpu.bat
```

启动后轮询 `/system_stats`（最多 120s），成功即把 `installPath` 写回 settings。

## P2 · 工作流发现

### 扫描位置

```
<install>/user/default/workflows/**/*.json   （递归 3 层）
<install>/workflows/**/*.json
```

### 能力推断

| 节点特征 | 能力 |
|---|---|
| `MiniMaxH3` / `H3Director` | 视频·H3 |
| 含 `LoadImage`/`LoadVideo` | 追加「参考生视频」 |
| `TextEncodeQwenImage21` / `QwenImage21Cache` | 图片 |
| 图片 + `LoadImage` | 追加「图生图」，否则「文生图」 |
| `indexTTS` | 语音 |
| `AceStep` / `YuE2` / `MusicGen` | 音乐 |

### 兼容性处理

- 同时支持 **UI 格式**（`nodes[]`）与 **API 格式**（`{id:{class_type}}`）；
- **子图**（`definitions.subgraphs`）内部的节点类型也参与能力推断；
- UUID 形式的节点类型（子图引用）不计入"缺节点"；
- `Note/MarkdownNote/Reroute/PrimitiveNode` 等前端节点不计入缺节点；
- 与 `/object_info` 比对，列出 `missingNodes`，工作流能不能跑一眼可见。
