# 工作流绑定流程（v1）

> 这份文档是**绑定工作的唯一权威流程**。配置助手提示词、插件设置页、以及任何来帮你绑定的 AI，
> 都以本文件为准执行；提示词里不再重复流程细节。
>
> 适用：DSH 插件 `dsh-omni-canvas`（画布 → 本地 ComfyUI）

---

## 0. 先做选择：用内置模板，还是绑定你自己的工作流

| 选项 | 适合谁 | 代价 |
|---|---|---|
| **A. 内置模板** | 想开箱即用、模型版本与模板一致 | 需要本机装有模板要求的**模型文件**与**自定义节点**；版本不一致时靠自动适配 |
| **B. 绑定自己的工作流** | 已有能跑的工作流 / 模型不同 / 想用别的模型 | 需要一步步绑定参数（本文档 §3） |

**默认不强制 A**：内置模板要不要启用，由用户在设置里勾选。未启用且没有可用绑定时，
插件应明确提示「请先在设置里完成绑定」，而不是抛模型缺失错误。

---

## 1. 环境前置检查（两条路都要跑）

| 检查项 | 方法 | 不通过时 |
|---|---|---|
| ComfyUI 地址可连通 | `GET /system_stats` | 提示填地址 / 启动 ComfyUI |
| ComfyUI 版本可读 | 同上返回的 `system.version` | 仅记录 |
| 工作流目录可读 | 扫描 `user/default/workflows/*.json` | 提示手动选文件 |
| 模型清单可读 | `GET /object_info` | 无法自动适配模型，转人工 |

### 1.1 自定义节点检查（仅方案 A 需要）

内置模板依赖的节点类型（缺一个就跑不动）：

| 节点类型 | 来源 | 缺了会怎样 |
|---|---|---|
| `ComfyMiniMaxH3Director` | H3 导演台插件 | 视频完全跑不了 |
| `MiniMaxH3DirectorSelfLift` | 同上 | 长镜/渐进采样缺失（可跳过） |
| `PathchSageAttentionKJ` | KJNodes | 加速补丁缺失（可跳过） |
| `MiniMaxH3MemoryEfficientSageAttentionPatch` | H3 插件 | 显存优化缺失（可跳过） |
| `VHS_VideoCombine` | VideoHelperSuite | 视频合成缺失（需退到 SaveVideo） |
| `TextEncodeQwenImage21` / `QwenImage21Cache` | Qwen-Image 2.1 节点 | 文生图跑不了 |

**判定方法**：`GET /object_info` 返回的 key 集合里查这些 class_type。

**缺失处理**：
1. 先告诉用户缺哪几个、分别来自哪个插件包；
2. 用户同意后，用 ComfyUI-Manager 的接口安装（`/manager/queue/install` 或 Manager 的 CLI）；
   Manager 不可用时，给出插件仓库地址 + 手动安装步骤（放进 `custom_nodes/` 后重启）；
3. 装完**必须重启 ComfyUI**（不是重启 DSH、不是刷新画布）——见 §1.2；
4. 只有校验通过，才允许启用方案 A。

---

### 1.3 模型下载（缺模型时）

模型基本都在 HuggingFace。**先问用户是否允许下载**（要联网、占磁盘），同意后再动手。

#### 判定「缺什么」

```
所需模型 = 内置模板引用的模型名（UNet / CLIP / VAE / LoRA / upscale）
本机已有 = GET /object_info 里对应模型输入的可选列表
差值 = 需要下载的清单
```

内置模板引用的模型见 `templates/*.json`；同时维护一份 `models.manifest.json`（见 §1.4）作为下载依据。

#### 下载方式（按优先级）

| 方式 | 命令/接口 | 说明 |
|---|---|---|
| ① ComfyUI-Manager 的模型列表 | Manager 面板「Model Manager」→ 搜 filename → Install | 最省事，模型已登记仓库地址 |
| ② `hf` CLI（新版） | `hf download <repo_id> <filename> --local-dir <ComfyUI>/models/<subdir>` | 需要 `pip install -U huggingface_hub` |
| ③ `huggingface-cli`（旧版） | `huggingface-cli download <repo_id> <filename> --local-dir ...` | 旧环境兼容 |
| ④ 直链下载 | `https://huggingface.co/<repo_id>/resolve/main/<filename>` + aria2c/curl | 无 Python 环境时兜底 |

**国内网络**：以上都支持镜像，设环境变量
`HF_ENDPOINT=https://hf-mirror.com`，或直链把 `huggingface.co` 换成 `hf-mirror.com`。

#### 目录对应（放错位置 = 还是找不到）

| 类型 | 目标目录 | object_info 输入名 |
|---|---|---|
| UNet / diffusion | `models/unet/`（或 `models/diffusion_models/`） | `unet_name` |
| CLIP / text encoder | `models/clip/`（或 `models/text_encoders/`） | `clip_name` |
| VAE | `models/vae/` | `vae_name` |
| LoRA | `models/loras/` | `lora_name` |
| 放大模型 | `models/upscale_models/` | `upscale_model_name` |

#### 下载后校验（缺一不可）

1. **文件存在且大小合理**（小于 100MB 的 `.safetensors` 基本是 LFS 指针或下载中断）；
2. 若 manifest 提供 `sha256` → 校验；
3. **重新拉 `GET /object_info`** 确认该模型出现在可选列表（ComfyUI 会扫描目录，通常无需重启；未出现则按 §1.2 重启 ComfyUI）；
4. 记录到绑定文件的 `warnings`：实际用了哪个版本。

#### 磁盘与失败处理

| 情况 | 处理 |
|---|---|
| 磁盘不足 | 先算总大小（manifest 里的 `size_gb`），提示预计占用，用户确认再下 |
| 下载中断 | 支持断点续传（`hf` 自带；直链用 `curl -C -` / `aria2c -c`） |
| 仓库需要授权（gated） | 提示用户先去 HF 页面同意条款并配置 `HF_TOKEN` |
| 找不到同款模型 | 按 §4 族名适配找替代；仍无 → 停下来问用户（不要瞎凑一个不想干的模型） |

### 1.4 `models.manifest.json`（插件自带的"需要哪些模型"清单）

```json
{
  "minimax_h3_hybrid_fl2va_ref2va_b25-49-int8.safetensors": {
    "kind": "unet", "subdir": "unet", "size_gb": 12.5,
    "repo": "<owner>/<repo>", "file": "…int8.safetensors",
    "note": "H3 主模型；没有就退回用户自己的视频工作流"
  },
  "qwen3vl_32b_minimax_h3_int8_convrot.safetensors": {
    "kind": "clip", "subdir": "clip", "size_gb": 18.0,
    "repo": "<owner>/<repo>", "file": "…"
  }
}
```

> 这张清单是**下载依据**，也是"内置模板能不能用"的判定依据。
> 清单里没登记的模型，只能靠 §4 族名适配或用户自己下载。

### 1.2 重启 ComfyUI 并复验（装完节点后必做）

> **要重启的是 ComfyUI 进程**。DSH / 画布 / 浏览器刷新都不会让新装的自定义节点生效。

按优先级尝试：

| 方式 | 做法 | 判定成功 |
|---|---|---|
| ① Manager 重启（推荐） | `POST /manager/reboot`（ComfyUI-Manager 提供） | 请求返回 200 |
| ② 手动/脚本重启 | 关闭启动 ComfyUI 的窗口或进程（`ComfyUI\main.py`、`run_nvidia_gpu.bat` 等），再启动一次 | 进程重新出现 |
| ③ 便携版 | 关掉 `ComfyUI.exe` / `run_cpu.bat` 窗口，重新双击启动 | 同上 |

**重启后必须复验三步**：

1. **等服务起来**：轮询 `GET /system_stats` 直到返回 200（超时 120s，超过就告诉用户「ComfyUI 没起来」并给启动方式）；
2. **确认节点已加载**：重新拉 `GET /object_info`，逐个查 §1.1 表里的 class_type 是否出现；
3. **确认模型仍在**：`object_info` 里对应模型输入的可选列表非空（重启后有时会因路径配置丢失模型）。

三步过完才允许启用内置模板；任一不过：
- 节点仍缺 → 说清哪个插件没装上、建议看 ComfyUI 启动日志里的 `IMPORT FAILED`；
- 模型为空 → 提示检查 `extra_model_paths.yaml` / 模型目录。

> 只重启 ComfyUI 期间，DSH 不需要重启、画布不会丢数据；恢复后直接重试用例即可。

## 2. 能力（capability）清单

| capability | 含义 | 典型用途 |
|---|---|---|
| `image-t2i` | 文生图 | 角色卡、场景板 |
| `image-edit` | 图生图 / 参考图编辑 | 改图、多参考合成 |
| `video-r2v` | 参考图生视频 | 主体一致的分镜 |
| `video-i2v` | 首帧生视频 | 尾帧链、续接 |
| `video-fl2v` | 首尾帧生视频 | 首尾锁定的转场 |
| `video-t2v` | 文生视频 | 空镜、环境 |

一个工作流可以绑多个 capability（同一份 H3 导演台可同时是 r2v/i2v/fl2v/t2v）。

---

## 3. 逐能力必须绑定的参数

> **原则：缺一个就是在跑一个假的配置**。宁可报错，也不要静默降级。

### 3.1 文生图 `image-t2i`

| 参数 | 目标 | 必需 | 找不到时 |
|---|---|---|---|
| `prompt` | 正向提示词输入（TextEncode 的 text/prompt） | ✅ | 停止，不能绑 |
| `seed` | 种子（KSampler/ RandomNoise 的 seed/noise_seed） | ✅ | 停止（否则每次同图） |
| `width` / `height` | `EmptyLatentImage` 的 width/height | ✅ | 停止（1K/2K 无效） |
| `count` | 同节点的 `batch_size`（1–4） | ✅ | 停止，并说明「该工作流不支持多张」 |
| `outputs.image` | `SaveImage` 节点 | ✅ | 停止（拿不到产物） |
| `negative` | 负向 TextEncode | 建议 | 记录「无负向」 |
| `steps` / `cfg` | KSampler / SamplerCustom 的对应字段 | 建议 | 记录「用工作流内置值」 |

### 3.2 图生图 `image-edit`

在 3.1 基础上追加：

| 参数 | 目标 | 必需 |
|---|---|---|
| `refImage` | `LoadImage` 的 `image` 字段 | ✅ |

（多参考图的工作流：按 `image1..imageN` 或 `image_1..image_N` 顺序绑，最多 4 张）

### 3.3 视频（H3 导演台系）

| 参数 | 目标 | 必需 |
|---|---|---|
| `prompt` | 导演台的 timeline JSON 内 `segments.0.prompt`（或 `global_prompt`） | ✅ |
| `seed` | 导演台 `seed` | ✅ |
| `length` | `total_frames`（24fps × 秒数） | ✅ |
| `width` / `height` | 导演台 `width`/`height` | ✅ |
| `taskType` | `task_type`（t2v/i2v/r2v/fl2v） | ✅（多模式共用一份工作流时） |
| `refImage`/`refImage2`/`refImage3` | 参考图槽（`global.refs[]` 或 `segments[].refs[]`） | r2v/i2v 必需 |
| `outputs.video` | `SaveVideo` / `VHS_VideoCombine` | ✅ |

**踩过的坑（务必遵守）**：
1. 有的导演台把 timeline JSON 存在 `widgets_values` 里，API 图上字段名可能是 `timeline_data` 或 `widget_11`；
   注入时要用「工作流自带的 timeline 当底稿」再改 `segments.0.prompt`，**不要凭空的 `{}` 造一个**（会把 segments 写成对象，跑挂）。
2. `VHS_VideoCombine` 可能是**静音(bypassed)**节点，实际输出走 `SaveVideo`；两个都查，取活的那个。
3** 模型版本要按族名适配（见 §4），不要硬编码文件名。

## 4. 模型自适应（用户模型版本不一致时）

1. 从 `/object_info` 取每个模型输入的可选列表；
2. 现值不在列表里 → 按族名切词匹配（`_ - . /` 分词，取长度 ≥3 的非数字词元，累计命中长度 ≥6 才算匹配）；
3. **LoRA 缺失 → 跳过该 LoRA 节点**，把下游 `model` 接到它的上游（LoRA 是增益，不是必需）；
4. **主模型（UNet/CLIP/VAE）缺失且无同类** → 停止，明确告知缺什么、本机有哪些相近的；
5. 所有替换都要写进 warning，让用户知道实际用了什么。

---

## 5. 自动推断规则（人不在时也能给出候选）

| 看什么 | 推断成 |
|---|---|
| 节点类型含 `TextEncode` 且无 image 输入 | `prompt` |
| 字段名 `seed` / `noise_seed` / `rand_seed` | `seed` |
| 节点类型含 `EmptyLatent` / `EmptySD3Latent` | `width`/`height`/`count`(batch_size) |
| 节点类型含 `KSampler` / `SamplerCustom` | `steps`/`cfg`/`seed` 候选 |
| 节点类型含 `SaveImage` | `outputs.image` |
| 节点类型含 `SaveVideo` / `VHS_VideoCombine` | `outputs.video` |
| 节点类型含 `LoadImage` | `refImage` |
| 节点类型含 `ComfyMiniMaxH3Director` | `prompt`(timeline)/`seed`/`total_frames`/`width`/`height` |

推断结果**必须让用户确认**（列出「我打算这样绑」的表格），不要直接保存。

---

## 6. 保存前校验

1. 节点 id 在提交图里真实存在（UI→API 转换后再查，不是查原始 UI 文件）；
2. 字段名在该 class_type 的 `input.required/optional` 里；
3. `outputs` 节点存在且**未被 bypass**；
4. 记录工作流文件 hash（文件变动后提醒重绑）。

---

## 7. 试跑验证（必须做，不许跳过）

| capability | 最小试跑 | 通过标准 |
|---|---|---|
| image-t2i | 512×512、`count=1`、seed 固定 | 返回 1 张图，尺寸与请求一致 |
| image-t2i（多张） | `count=4` | 返回**4 张**（验证 `count` 真绑上了） |
| image-edit | 1 张参考 + 短提示词 | 返回图，内容跟随参考 |
| video | 3 秒、1 张参考 | 返回视频，时长≈3s，有音轨 |

试跑失败：把 ComfyUI 的原始报错**翻译成人话**告诉用户（缺模型 / 缺节点 / 显存不足 / 字段不存在），
不要只回一句「执行报错」。

---

## 8. 保存与设为默认

1. 绑定写入 `~/.dsh/omni-canvas.bindings.json`，字段：`capability / name / workflow{file,format,hash} / inputs / outputs / verified`；
2. `verified.mode = "run"` 才允许出现在卡片的可选列表里；
3. 设为默认时，写 `defaults[capability] = <绑定 id>`；
4. **默认实现的选择顺序**：用户指定的绑定 → 用户启用的内置模板 → 内置模板（仅当模型齐备）→ 报错并引导绑定。

---

## 9. 失败与回退

| 情况 | 处理 |
|---|---|
| 绑定失败 | 保持内置模板不变，明确说明原因 |
| 绑定后跑不通 | 保留绑定但 `verified.mode = "structure"`，不出现在可选列表 |
| 工作流文件被移动/删除 | 启动自检发现 hash 不匹配 → 提示重绑 |
| 用户换机器 | 绑定文件可整体拷贝；但模型/节点需按 §1 重新检查 |
| 装了节点没生效 | 99% 是**没重启 ComfyUI**（不是 DSH），按 §1.2 重启并复验 |

---

## 10. 给 AI 助手的最短指令（提示词里只放这段）

> 按 `dsh-omni-canvas/docs/工作流绑定流程.md` 执行：先 §0 问用户选内置还是自绑；自绑走 §3 的逐能力参数清单，
> §5 的推断只用来给候选、必须让用户确认；§6 校验、§7 试跑（文生图必须试 `count=4`）、§8 保存并设默认。
> 模型不一致按 §4 适配（缺 LoRA 跳过、缺主模型就停）。任何失败都要把人话原因说清楚，不要静默降级。
