# 夜间自主开发计划（2026-10-29 夜）

> 目标：在不打扰用户的前提下，把插件从"能用"推进到"别人也能用、出错能自解释"。
> 纪律：每步验证 + 提交 + 推送；需要用户决策的写进「待确认」，不阻塞。

## 一、夜间工作纪律（必须遵守）

1. **每阶段开始前** `git commit` 一个 checkpoint（可回滚）。
2. **每次改完**：`node --check` → 跑自测脚本 → 至少一次真实 API 冒烟 → commit → push。
3. **GPU 使用限制**：夜间不跑重型任务（H3 视频 90s+ / bf16 大模型）；视频类只做 dry（转换+结构校验）。图片类单次 ≤ 240s。
4. **ComfyUI 可用性**：每轮开始先探活；挂了用 WMI 拉起（`python -m ... main.py`），连续 2 次起不来就停该项并记录。
5. **失败隔离**：某项连续 2 次修不好 → 记入「受阻」清单，跳到下一项，不空转。
6. **不动用户数据**：不删项目、不改 `~/ .dsh/projects`；绑定改动只做增量。
7. **兼容优先**：保持内置模板（t2i-fast / t2i-hq / edit / h3-r2v）始终可用。
