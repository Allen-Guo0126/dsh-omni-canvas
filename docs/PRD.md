# DSH ComfyUI 画布插件 · 需求文档（v0.1 讨论稿）

> 状态：需求确认中
> 日期：2026-10-28
> 目标读者：产品 / 开发 / 你

---

## 1. 背景与目标

### 1.1 背景

DSH 现有插件 `@huanlin/dsh-plugin-aigc-canvas` 提供了一块右侧无限画布，但它是**模型驱动**的：
只有在对话里让 AI 调 `aigc_canvas_place` 才能往画布上放素材，人没有"新建节点 / 点生成"的入口，
所以作为创作工具无法直接使用。

本插件参考 BeefTV 的形态：**画布上能手动建节点、点生成；同时 AI 也能改这张画布**。
生成能力**直连本地 ComfyUI**（不经过独立的适配服务），工作流模板内嵌。

### 1.2 目标

| 目标 | 判据 |
|---|---|
| 人能独立完成一次创作 | 新建项目 → 建节点 → 点生成 → 出图/出片 → 无需写代码 |
| AI 能操作同一张画布 | 对话里说"把这条镜头生成到画布上"，节点出现并自动连线 |
| 小白可用 | 首启自检 + 缺模型时给出可执行提示，而不是 400 |
| 本地、无云依赖 | 只连 `127.0.0.1:8188`（ComfyUI） |

### 1.3 非目标（v1 不做）

- 云端渲染 / 多人协作
- 视频剪辑时间线（拼接、字幕轨）
- 局部重绘、超分、全景、视角调整
- 表情/口型编辑等专业后处理

## 2. 用户与场景

### 2.1 用户

- **主用户**：内容创作者/运营，装好 ComfyUI 与模型，但不想搭工作流。**动手能力弱**。
- **次用户**：会用对话驱动 AI 的高级用户（就是你现在这种用法）。

### 2.2 核心场景

1. **单图出图**：一句话 → 图片节点 → 生成 → 4 张备选 → 挑一张继续改。
2. **图生图**：挂一张参考图 → 改环境/服装/风格 → 出图。
3. **参考图生视频**：挂角色卡/场景图 → 写镜头描述（含台词）→ 出 5–8 秒带声音视频。
4. **AI 驱动**：对话里说"按这个分镜把 4 个镜头生成到画布"，AI 建节点、绑参考、提交生成。

## 3. 产品形态

### 3.1 画布 = 项目

- 一个画布就是一个项目；**支持新建 / 重命名 / 删除 / 切换**多个画布。
- 画布状态（节点、连线、视口、参数）持久化，关掉重开可恢复。
- 每个画布独立素材目录，互不污染。

> **已确认（Q1）**：画布**不绑定会话**——它是独立项目，按项目新建 / 切换；
> 会话只是"打开某个项目"的入口之一，关掉会话项目仍在（存储在项目目录，不随会话销毁）。

### 3.2 右侧面板

- 挂在 better-sidebar 的一个 tab（与现有插件并存，不覆盖）。
- 布局：顶部工具栏 / 中间无限画布 / 右侧选中节点参数抽屉。

### 3.3 工具栏

| 按钮 | 行为 |
|---|---|
| ＋ 图片 | 在视口中心建一个图片节点（空提示词） |
| ＋ 视频 | 建一个视频节点 |
| ＋ 参考图 | 从本地文件上传一张图，作为参考节点 |
| 项目 | 新建 / 切换 / 重命名 / 删除 |
| 自检 | 重新检测 ComfyUI 与模型可用性 |

## 4. 能力清单（v1）

统一使用 **Qwen-Image-2.1 加速版**（viggle-turbo 6 步）与 **H3 导演台 r2v**。

| # | 能力 | 底层工作流 | 关键参数 | 预期耗时 |
|---|---|---|---|---|
| C1 | 文生图 | `qwen-t2i-fast`（int8 turbo 6 步） | 提示词、画幅、张数 | 6–8 秒/张 |
| C2 | 文生图（高质量） | `qwen-t2i-hq`（bf16 + viggle LoRA） | 同上 | 12–20 秒/张 |
| C3 | 图生图 | `qwen-edit`（viggle 6 步 + 参考图） | 参考图、提示词、画幅 | 17–20 秒 |
| C4 | 参考图生视频 | `h3-director-r2v`（H3 导演台，8 步 + SelfLift） | 提示词、1–3 张参考图、时长、画幅、分辨率档 | 60 秒/5 秒片 |

### 4.1 参数暴露原则

- **面向用户只暴露**：提示词、画幅、张数、时长、参考图、档位（快/高清）。
- **全部封装在模板里**：steps、cfg、sampler、scheduler、LoRA 组合、SelfLift、VAE、seed 策略。
- 高级用户可在"开发模式"下看到并覆盖原始字段（v1 可后置）。

> **待确认 Q2**：视频默认时长与画幅？
> 建议默认 6 秒 / 9:16，可选 4/6/8/10 秒；分辨率档 480p / 768p / 1080p（短边）。
> H3 帧数需对齐 4n+1，服务端就近取整（6 秒 → 6.04 秒），是否接受这种 ±0.05 秒误差？

> **待确认 Q3**：视频是否默认同时生成音频？
> H3 是 AV 模型，默认带声音与环境音轨；台词用 `<d>[Chinese] …</d>` 写在提示词里。
> 是否提供"静音"开关（会牺牲一部分真实感）？

## 5. 节点模型

| 节点类型 | 作用 | 关键字段 |
|---|---|---|
| `prompt` | 纯文本/提示词，可连到生成节点 | text |
| `image` | 图片（生成结果或上传参考） | file, w, h, prompt, params, status |
| `video` | 视频 | file, duration, fps, hasAudio, prompt, params, status |
| `generate` | 生成指令节点（可选，也可直接在 image/video 节点上点生成） | capability, refs[], params |

### 5.1 底部输入条（Composer）— v1 核心交互

**选中任一图片 / 视频节点 → 画布底部弹出输入条**（与现有插件一致的形态）：

```
┌──────────────────────────────────────────────────────────┐
│ 描述要生成的图片内容 / 镜头描述…                    字号 −+ ⤢ │
│                                                          │
│ [qwen-t2i-hq ▾]              ⚙ 168 ▣ 1K · 自动 · 1张   ➤ │
└──────────────────────────────────────────────────────────┘
```

| 控件 | 图片节点 | 视频节点 |
|---|---|---|
| 提示词 | 多行输入，支持 ↑ 发送 | 多行输入，支持六段式；台词写 `<d>[Chinese] …</d>` |
| 模型 | `qwen-t2i-fast` / `qwen-t2i-hq` / `qwen-edit` | `h3-director-r2v` |
| 画幅 | 9:16 / 16:9 / 1:1 | 9:16 / 16:9 / 1:1 |
| 分辨率档 | 1K / 2K（长边） | 480p / 768p / 1080p |
| 张数 | 1–4 | — |
| 时长 | — | 4 / 6 / 8 / 10 秒 |
| 音频 | — | 开 / 关（默认开） |
| 参考图 | 取节点已连的 `image` 上游（0–N） | 取已连参考图（1–3 张，含角色/场景卡） |
| 发送 | ⏎ 或 ➤ 按钮 | 同左 |

规则：
- 输入条内容与节点绑定：切换节点即切换该节点的提示词与参数（不串稿）。
- 生成中：输入条禁用并显示进度；节点上显示进度环。
- 生成完成：节点更新为新产物，**旧产物进资产库**（§12）。
- 视频节点额外显示音轨标记与时长（如 `6.04s · 有声`）。

### 5.2 交互

- 拖拽移动、框选、缩放（滚轮/触控板）、画布平移（空格拖拽或中键）。
- 连线 = 数据依赖：`参考图 → 生成节点`、`提示词 → 生成节点`。
- 选中节点 → 右侧抽屉显示参数；双击节点 → 放大预览 + 元数据（提示词、模型、耗时）。
- 生成中：节点显示进度环 + 阶段文字（排队 / 采样 / 解码）。
- 失败：节点显示红色状态 + **可读原因**（缺模型 / 节点缺失 / 显存不足 / 队列满）。

## 6. 用户体验流程

### 6.1 首次使用

1. 打开 tab → 自检（ComfyUI 可达？模型齐？节点齐？）
2. 全部通过 → 空画布 + 引导文案（"点 ＋图片 开始"）
3. 缺东西 → 明确列表："缺少 `qwen_image_2.1_vae_bf16.safetensors`，请放到 `ComfyUI/models/vae/`"

### 6.2 生成一张图

```
＋图片 → 输入提示词 → 选画幅 9:16 → 点"生成" → 进度 → 出图（4 张可切换）
        ↓ 满意
      双击查看参数 → "以此图继续" → 新建图生图节点（自动连线）
```

### 6.3 生成一段视频

```
＋视频 → 挂 1–3 张参考图（拖拽连线）→ 输入镜头描述（六段式或自然语言）
       → 时长 6s / 9:16 / 768p → 生成 → 排队(第 N 位) → 采样 → 出片（带音轨）
```

## 7. AI 如何操作画布

保留现有 `aigc_canvas_place / link / unlink / list_elements` 语义，新增：

| 工具 | 作用 |
|---|---|
| `comfy_canvas_create_project(name)` | 新建项目（画布） |
| `comfy_canvas_list_projects()` | 列出项目 |
| `comfy_generate_image(nodeId?, prompt, refs[], params)` | 提交文生图/图生图到指定节点或新节点 |
| `comfy_generate_video(nodeId?, prompt, refs[], params)` | 提交视频任务 |
| `comfy_job_status(jobId)` | 查询任务 |
| `comfy_self_check()` | 返回本机可用能力清单（模型/节点/显存） |

约定：AI 建节点后**必须**把节点 id 回报给用户；生成的媒体落在画布目录并连好依赖边。

### 7.1 与 Skill 协作（v1）

插件**不重复实现提示词知识**，而是与 DSH 的 Skill 体系打通：

| 环节 | 谁来做 |
|---|---|
| 六段式骨架、各模式（t2v / i2v / r2v）的字段与注意点 | 插件内置一份**骨架模板**（`prompt-templates/h3-*.json`），输入条 `/` 直接插入 |
| 需要"把一段中文拍摄想法写成合格 H3 提示词" | 会话里由 Agent 加载 `write-minimax-h3-video-prompts` / `h3-prompt-writing` skill 撰写，再调 `comfy_generate_video` 提交 |
| 写成之后回填画布 | `comfy_canvas_set_prompt(nodeId, prompt)` 或直接 `comfy_generate_video(prompt=…)` |

新增工具：

| 工具 | 作用 |
|---|---|
| `comfy_prompt_template(mode)` | 返回对应模式（`t2v`/`i2v`/`r2v`）的六段式骨架 + 约束（台词 ≤16 字、参考图编号规则等），供 Agent 直接使用 |

**分工原则**：插件负责"骨架与格式正确"，Skill 负责"内容写得好"；两边都产出同一种六段式文本，可以互相覆盖。

## 8. 技术架构

```
┌─ DSH 右侧面板（React, better-sidebar tab）──────────┐
│ 工具栏 · 无限画布 · 节点参数抽屉 · 进度              │
└───────────────────┬────────────────────────────────┘
                    │ RPC（宿主工具 / 事件）
┌───────────────────▼────────────────────────────────┐
│ 插件宿主（Node，cordis 插件）                       │
│  ├ 能力层：C1–C4（UI 只见能力，不见工作流）          │
│  ├ 模板注册表：JSON 模板 + 参数 schema + requires    │
│  ├ 自检：/object_info、模型清单、显存               │
│  ├ 队列：单卡串行 + 并发上限 + 排队位置              │
│  ├ 进度：WS /ws 订阅 + /history 兜底                │
│  └ 直连 http://127.0.0.1:8188                       │
└─────────────────────────────────────────────────────┘
```

### 8.1 关键接口（ComfyUI 原生）

| 用途 | 接口 |
|---|---|
| 自检 | `GET /object_info`、`GET /system_stats` |
| 上传参考图 | `POST /upload/image` |
| 提交 | `POST /prompt`（API 格式工作流） |
| 进度 | `WS /ws?clientId=…`（`executing` / `progress`） |
| 结果 | `GET /history/{prompt_id}` |
| 下载媒体 | `GET /view?filename=…&type=output` |
| 队列 | `GET /queue` |

### 8.2 模板格式（内嵌，随插件发版）

```json
{
  "id": "qwen-t2i-fast",
  "capability": "text2image",
  "label": "Qwen-Image 2.1 加速版",
  "requires": { "models": ["qwen_image_2.1_...safetensors"], "nodes": ["TextEncodeQwenImage21"] },
  "params": {
    "prompt":  { "type": "text" },
    "size":    { "type": "enum", "values": ["9:16","16:9","1:1"], "default": "9:16" },
    "count":   { "type": "int", "min": 1, "max": 4, "default": 1 }
  },
  "workflow": { "…": "API 格式节点图" },
  "bindings": {
    "prompt": ["6", "text"],
    "size":   ["17", "size"],
    "seed":   ["3", "seed"]
  }
}
```

**为什么内嵌模板 + `requires`**：模板绑定的是模型文件名与节点名，不同机器不同；内嵌 + 自检可以在提交前就判断"这台机器能不能跑"，给出可读提示，而不是等 ComfyUI 返回 400。

### 8.3 存储

| 内容 | 位置 | 说明 |
|---|---|---|
| 画布 JSON | 项目目录（待定 Q1） | 节点、连线、视口、参数 |
| 媒体文件 | 项目目录/media | 从 ComfyUI 下载后落盘，不依赖其 output 目录 |
| 任务记录 | 画布 JSON 内节点 meta | 含 prompt_id、状态、耗时，便于恢复 |

## 9. 非功能需求

| 项 | 要求 |

## 11. 决策记录（2026-10-28 已确认）

| # | 问题 | 结论 |
|---|---|---|
| Q1 | 画布绑定会话还是工作区？ | **不绑定会话**。画布是独立项目，按项目切换；会话只是"打开某个项目"的入口之一 |
| Q2 | 视频默认值 | 6 秒 / 9:16 / 768p（可调 4–10 秒、480p–1080p） |
| Q3 | 视频是否带音频 | **默认带音频**（H3 自带音轨），保留静音开关 |
| Q4 | ComfyUI 谁装 | **用户自己装**；插件只做轻量引导（检测不到时给安装指路），v1 不做复杂自检修复 |

| Q6 | 多画布 tab | **单 tab + 项目切换**（顶部项目下拉/列表） |
| Q7 | 重生成与历史 | 节点重新生成 **覆盖该节点**；**所有生成产物进入「资产库」永久保留**（见 §12） |
| Q8 | 导出 | v1 **不做** |
| Q9 | 模板管理 | v1 **不做**（模板随插件包内嵌，不做远端更新/可视化管理） |
| Q10 | i2v 首尾帧 / 图生视频 | v1 **不做**（先只做参考图生视频 C4） |

## 12. 资产库（v1 必须）

- **定位**：所有生成产物（图片/视频）的**永久归档**，与画布节点解耦。
- 节点只是"引用"：节点重新生成 → 节点指向新产物并覆盖显示；旧产物仍在资产库。
- 资产条目字段：`id | 类型 | 文件 | 提示词 | 模型 | 参数 | 来源节点 | 生成时间 | 耗时 | 状态`。
- 入口：右侧面板切换到「资产库」视图（与画布同一 tab 内的二级视图）。
- 操作：预览、拖回画布（生成新节点）、复制提示词/参数、删除。
- 存储：项目目录下的 `assets/`，索引写 `assets/index.json`。
- 与画布的联动：从资产库把图片拖到画布 → 新建 `image` 节点并复制原始 prompt/params（便于"以此继续"）。

## 13. 风险

| 风险 | 影响 | 缓解 |
|---|---|---|
| 用户机器模型不全 | 生成直接失败 | 自检前置 + 明确缺失清单 |
| 节点包版本漂移 | 模板失效 | 提交前用 `/object_info` 校验输入名/枚举 |
| 显存不足 / 排队久 | 体验差 | 队列可视化 + 分辨率档降级建议 |
| ComfyUI 未启动 | 一片空白 | 自检提示 + 一键启动（可后加） |
| 模板爆炸 | 维护成本 | 模板 JSON 化 + 按能力分组 + 版本化 |

## 14. 自检补充需求（v0.2，待确认）

> 逐节复核后发现的遗漏点，按「必须 / 建议 / 后置」标注。**打 ✅ 的会进 v1**。

### 14.1 连接与配置

| 项 | 说明 | 优先级 |
|---|---|---|
| ComfyUI 地址配置 | 默认 `http://127.0.0.1:8188`，可在插件页改（换机器/换端口） | ✅ 必须 |
| 连接状态指示 | tab 顶部一个小圆点：绿=连通 / 黄=队列忙 / 红=连不上（点击可见原因） | ✅ 必须 |
| 重连与超时 | 请求超时默认 30s（提交）/ 长任务轮询；断线自动重试 3 次 | ✅ 必须 |
| 启动引导 | 检测不到时提示：「ComfyUI 未启动，请在 ComfyUI 目录运行 main.py / 打开桌面版」+ 文档链接 | ✅ 必须 |

### 14.2 画布编辑能力（原 PRD 缺失）

| 项 | 说明 | 优先级 |
|---|---|---|
| 删除节点 / 连线 | 选中按 `Delete`，或节点右上角菜单 | ✅ 必须 |
| 撤销 / 重做 | `Ctrl+Z` / `Ctrl+Shift+Z` | 后置（已确认 v1 不做） |
| 节点重命名 | 节点标题可编辑（如「图片节点 8 ✎」） | ✅ 必须 |
| 快捷键 | 空格拖拽平移、滚轮缩放、`Ctrl+0` 适应画布、`Ctrl+A` 全选 | ✅ 必须 |
| 多选与批量 | 框选多个节点 → 批量删除 / 批量生成（同参数） | 建议 |
| 对齐与吸附 | 网格吸附（8px），可选关闭 | 后置 |

### 14.3 生成控制（原 PRD 只有「提交」）

| 项 | 说明 | 优先级 |
|---|---|---|
| 取消生成 | 生成中可取消：调 ComfyUI `POST /interrupt` + 清队列项；节点回 idle | ✅ 必须 |
| 失败重试 | 节点红框 + 「重试」按钮，复用上次参数 | ✅ 必须 |
| 种子 | 面板可填 seed；留空=随机，并把实际 seed 写进节点 meta（可复现） | ✅ 必须 |
| 生成队列面板 | 右下角浮层：当前任务 + 排队列表（H3 一条 60s，必须让用户看见在等） | ✅ 必须 |
| 提示词模板 | 输入条内「/」唤出：**H3 六段式骨架**（文生视频 / 图生视频 / 参考生视频三种）、景别、风格词，一键插入 | ✅ 必须（已确认） |
| 提示词历史 | 输入框下拉显示最近 20 条 | 建议 |

### 14.4 媒体与资产

| 视频播放 | 节点内播放/暂停/静音/进度，右键「下载」 | ✅ 必须 |
