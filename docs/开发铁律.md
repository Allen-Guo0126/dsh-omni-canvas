# 开发铁律（硬性门禁）

> 本文件是**不可协商**的流程约束。任何改动，无论大小，都必须走完对应门禁才能算"做完"。
> 违反门禁的提交等于没做。

## 0. 一句话原则

**"改完" 不等于 "能跑"；"能跑" 不等于 "我看过它真的对"。**
每次改动都要：**自测 → 截图自审 → 记录结果**，三者缺一不可。

## 1. 每次改动的最小门禁（必跑）

| # | 门禁 | 命令 | 通过标准 |
|---|---|---|---|
| 1 | 语法 | `npm run check`（= `check-all` + `check-imports` + `check-builtins`） | 全绿；新增文件必须被检查覆盖 |
| 2 | 接口契约 | `node scripts/routes-full.mjs` | 客户端会调的接口全部可执行，无 `is not defined` / 500 |
| 3 | 启动 | `node scripts/boot-smoke.mjs` | `apply()` 成功 + 真实路由调用返回 200 |
| 4 | 客户端 | `node scripts/client-smoke.mjs` | 产物可加载、CanvasApp 可执行、事件处理器无未定义引用 |
| 5 | **真机截图自审** | `powershell.exe -NoProfile -File scripts/shot.ps1 -OutPath E:\Allen\.tmp\shots\<name>.png` 后 `read_image` | **必须亲眼看图**，逐项核对布局/间距/字号/按钮位置 |

> 涉及生成能力（图片 / 视频 / 超分 / 口播 / 音色 / 翻译）时，额外加：
> `node scripts/e2e.mjs`、`voice-smoke.mjs`、`voice-video-e2e.mjs`、`translate-mask-test.mjs`（按改动范围选）。

## 2. 截图自审的具体要求

- **必须看图**，不能只凭"代码里写了"判断 UI 是否正确。
- 图里要能覆盖本次改动的区域；必要时**分开截图**（画布 / 弹窗 / 卡片工具条）。
- 审的时候逐条问自己：
  1. 间距是否异常（多出空白 / 挤在一起）？
  2. 字号是否可读（正文 ≥ 15px）？
  3. 按钮位置是否符合直觉（同功能按钮是否一致）？
  4. 有没有被遮挡、溢出、错位、重叠？
  5. 空状态 / 有数据状态**两种**是否都正常？
- 发现问题**当场修**，修完**重新截图**确认，不许"下次再说"。

## 3. 绝不允许的行为

| 禁止 | 原因 |
|---|---|
| 用真实项目 / 真实卡片做测试 | 会污染用户数据（曾把提示词写成测试文案、把成片换成测试视频） |
| 只跑语法就说"做完了" | 曾因此上线了「接口全 500、首页空白」 |
| 用长 sleep 阻塞式等待生成 | 生成 ~40s 就够；应「提交 → 立刻返回 → 稍后短查询」 |
| 提交未经截图核对的 UI 改动 | 间距/位置类问题只能靠眼睛发现 |
| 一次改多个互不相关的功能 | 出问题时无法定位；必须分步验证 |

## 4. 测试数据隔离规则

- 需要画布验证时：**新建临时节点 + 临时连线**，用完立刻删除并恢复画布（参考 `scripts/voice-fallback-submit.mjs` 的备份/恢复写法）。
- 需要真实生成时：用**独立临时项目**，或明确告知用户"我要在你某个项目里跑一条"，得到确认再做。
- 任何 `canvas.save` 之前必须先 `canvas.get` 拿最新快照，避免覆盖用户编辑。

## 5. 记录要求

每轮改动结束，在提交信息里写清：

```
feat|fix(scope): 做了什么
  - 自测：<跑了哪些门禁，结果如何>
  - 自审：<截图看到了什么，修了哪些问题>
```

并对用户汇报时**给证据**（数字、截图路径、失败项），不要只说"已完成"。

## 6. 能力清单（当前可用的自测手段）

| 手段 | 命令 | 覆盖 |
|---|---|---|
| 语法/引用/内建 | `npm run check` | 全仓静态正确性 |
| 接口全量 | `routes-full.mjs` | 30 个客户端接口 |
| 启动 + 路由 | `boot-smoke.mjs` | apply / 路由 / 405 / 404 |
| 客户端渲染 | `client-smoke.mjs` | 产物加载 / CanvasApp / 事件处理器 |
| 图片/视频/超分/口播 | `e2e.mjs` | 真实 ComfyUI |
| 音色 | `voice-smoke.mjs` / `voice-video-e2e.mjs` / `voice-multi-e2e.mjs` | TTS + refAudios 注入 |
| 翻译 | `translate-mask-test.mjs` | 占位符保护 12 项 |
| **真机截图** | `shot.ps1` | DSH 窗口画面 |

## 7. 已知限制（诚实记录）

- 截图只能"看"，不能"点"：GUI 有鉴权（401），无头浏览器进不去；DSH 未开调试端口。
  若需全自动点击，需用户在启动 DSH 时加 `--remote-debugging-port=9222`。
- 截图会短暂抢焦点（< 1 秒）。
- `client-smoke` 用桩 DOM，能验证"不崩"，不能验证视觉效果——视觉必须靠截图。
