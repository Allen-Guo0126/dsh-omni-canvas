# 工作流绑定：从"结构校验"到"端到端出图"

## 新增能力（在原有 inspect/save/list/test 之上）

| 工具 | 说明 |
|---|---|
| `cnv_binding_run` | 用绑定执行：UI→API 转换 + 参数回填 + 提交 + 等产物；`dry:true` 只转换不提交 |
| `cnv_binding_test` `mode:"run"` | 真跑一次，成功后把 `verified.mode` 记为 `run` |

工具总数：22 → **27**。

## UI→API 转换器

输入：UI 格式（`nodes/links`）；输出：`{id: {class_type, inputs}}`。

处理规则：

| 情况 | 处理 |
|---|---|
| 连线输入 | 解析 `links` → `[源节点id, 槽位]` |
| `Reroute` | 穿透，继续追上游 |
| `PrimitiveString/Int/Boolean` | 取 `widgets_values[0]` 作为字面量 |
| `widgets_values` 是数组 | 按 `/object_info` 的 required+optional 顺序对齐字段名 |
| `widgets_values` 是对象 | 直接按 key 映射 |
| 连接口类型（MODEL/CLIP/LATENT…） | 不当作 widget |
| `fixed/increment/decrement/randomize` | 跳过（不是真输入） |
| 静音节点（mode 2/4） | 跳过并记入 `issues` |
| `Note/MarkdownNote/Reroute` | 跳过 |

## 端到端实测（本机 z-image 文生图工作流）

绑定：

```json
{
  "capability": "image-t2i",
  "name": "z-image 文生图（本机）",
  "workflow": { "file": "user/default/workflows/z-image文生图工作流_api.json" },
  "inputs": {
    "prompt": { "node": "70", "field": "text" },
    "seed":   { "node": "69", "field": "seed" },
    "width":  { "node": "76", "field": "width" },
    "height": { "node": "76", "field": "height" }
  },
  "outputs": { "image": { "node": "67" } }
}
```

执行：

```
inspect  → 9 节点 / 缺节点 0 / prompt=70.text / seed=69.seed / 输出 67
save     → id = image-t2i-04db45
run      → ok，15.3s，产物 ComfyUI_00859_.png（640×640 红苹果）
test run → ok，2.9s，verified.mode 自动写为 run
```

产物：`E:\Allen\.tmp\e2e-out\ComfyUI_00859_.png`

## 设置页状态

| 显示 | 含义 |
|---|---|
| 当前：你的工作流 · <名字> `使用中` `已验证` | 绑定 + run 成功 |
| 候选 `已接入 · 已验证` | 绑定过且跑通 |
