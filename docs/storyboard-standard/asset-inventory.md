# 资产清单（STEP 3 的前置门）

> 拿到剧本后**第一件事**：先列资产清单，让创作者确认「哪些建卡、哪些不建」，再动手出图。
> 不做这一步直接出图，会同时浪费算力和漏掉一致性资产。

## 1. 三类资产与抽取规则

| 类别 | 建卡条件（满足任一即建） | 不建卡（直接在镜头描述里写死） |
|---|---|---|
| **人物** | 有名字 / 有台词 / 有独立动作 / 需要被认出（含只出现在回忆、照片里的人） | 纯背景路人（走过、站着的群众，不需要认出） |
| **场景** | 有对话或动作发生的主场景；同地点在不同时间/天气反复出现（按变体算） | 只被提及、不给信息、镜头不落地的地点；纯过场空镜 |
| **道具** | 被反复出现 / 被特写 / 影响剧情（信、手机、钥匙、病历、照片…） | 装饰性陈设（桌上的书、墙上的画），除非被拿起或特写 |

**一句话判据**：这个对象如果每镜长得不一样，观众会不会出戏？会 → 建卡。

## 2. 变体规则

同一资产在不同状态下要各出一张，命名沿用 `·<状态>`：

- 人物：`换装 / 湿身 / 受伤 / 年龄跨度 / 伪装`
- 场景：`白天 / 夜 / 雨`（同地点不同光气候也要分卡，否则跨镜光会跳）
- 道具：`完好 / 损坏 / 打开 / 使用中`

变体要真的不同才分卡；同一状态不要重复出卡（复用已有卡）。

## 4. 声线样本（有台词角色才出）

- 每个**有台词**的角色出一段 **5 秒左右**的声线样本（TTS，情绪中性，用该角色的说话方式）
- 存成音频资产 `voice:<id>`；台词镜生成时作 `audio_ref_nodes` 传给 H3（H3 自己把台词说出来，口型/音色一致）
- **没台词的角色不出**声线样本
- 约束：参考音频 ≤3 段、每段 2–15 秒、总 ≤15 秒，且必须同时传参考图

## 5. 门控与顺序

1. 出清单 → **停，等创作者确认**（可以增删、可以改判「建卡/不建卡」）
2. 确认后才出图；出图顺序建议：主角 → 主要配角 → 场景 → 道具（先看脸对不对，再往下跑）
3. **镜头表不依赖图片文件**，可在出图同时并行编写；但**逐镜生成必须等卡都在画布上**
4. 缺卡时不要硬跑：写 `PLAN-<槽位>`（挂图计划）并在本轮报告里点名缺口

## 6. 常见错误

- 只按「有台词」筛人物 → 漏掉靠肢体演出/需要认脸的角色
- 场景不分时段 → 同一地点白景夜景混用，成片光会跳
- 道具不入卡 → 跨镜的信封/手机长得不一样，观众直接出戏
- 给背景路人建卡 → 卡数翻倍，成本上升却没有收益
- 角色卡出成「单人全身照」而非合成版 → 脸不稳，见 `character-card-spec.md`
