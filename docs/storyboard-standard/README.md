# 分镜流程标准（2026-10 起）

本目录是**流程标准的版本化副本**。权威文件在 DSH 技能目录：

```
C:\Users\Administrator\.dsh\skills\story-short-generator\
├── SKILL.md                          ← 流程主文件（STEP 0–8）
└── references\
    ├── character-card-spec.md        ← 角色卡版式（本目录同名文件的来源）
    └── asset-inventory.md            ← 资产清单规则（本目录同名文件的来源）
```

改标准 = 改 `~/.dsh/skills/...` 里的文件，再同步复制到本目录，避免仓库副本与运行副本漂移。

## 这次固化的两条标准

### 1. 角色卡：16:9 合成版（一个角色一张）

```
┌───────────┬──────────────────────────────────────┐
│  大头照    │      全身三视图（正 / 侧 / 背）        │
│  1/3 宽    │          2/3 宽                      │
└───────────┴──────────────────────────────────────┘
                16:9 · 纯底 · 零文字 · 含鞋
```

- 取代原「单视图 + 三视图两张」规则；**不再配对双版本**
- `fast` 档另出单视图兜底卡（合成卡含 4 个身体，fast 必出副本）
- 已验证 prompt 模板在 `character-card-spec.md` 第 2 节（一次生成即达标）

### 2. 资产清单门（STEP 2.5，硬门控）

剧本拿到后**先列清单**、等创作者确认「建卡 / 不建卡」，再出图：

| 类别 | 建卡 | 不建卡 |
|---|---|---|
| 人物 | 有名字 / 有台词 / 有独立动作 / 需要被认出 | 纯背景路人 |
| 场景 | 有对话或动作落地的主场景（按时段/天气分变体） | 只被提及、镜头不落地 |
| 道具 | 反复出现 / 被特写 / 影响剧情 | 装饰性陈设 |

- 变体：人物 换装/湿身/受伤/年龄；场景 白天/夜/雨；道具 完好/损坏/打开
- **有台词角色**出 5 秒 TTS 声线样本（`voice:` 资产），无台词不出
- 镜头表可与出图并行；**逐镜生成必须等卡进画布**

## 流程总览（改后）

```
STEP 0 需求与规格门 → STEP 1 简报 → STEP 2 大纲
   → STEP 2.5 资产清单门（新）→ STEP 3 角色卡（合成版）
   → STEP 3.5 声线样本（TTS 5s）→ STEP 4 场景卡 → STEP 4.5 道具卡
   → STEP 5 七列镜头表 → STEP 5.5 自检门 → STEP 6 分镜
   → STEP 7 逐镜生成（r2v 绑卡 + audio_ref 声线）→ STEP 8 拼接交付
```

## 与插件工具的对接

- 角色卡：`comfy_generate_image(width=2048,height=1152, character="<名字>", title="角色卡·<名字>")`；合成卡**不传 `card_variant`**（它既不是 single 也不是 three）
- `fast` 兜底卡：`card_variant="single"`、2:3 竖版
- 视频绑定：`canvas_get_state().characterCardVariant` 兼容键 —— `three`=合成版主卡、`single`=单视图；合成卡缺 `cardVariant` 元数据时工具会给「找不到配对」warning 并按原卡使用（**预期行为**）
