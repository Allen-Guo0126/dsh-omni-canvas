# 角色卡标准（合成版）

> 标准版式，2026-10 起生效。**一个角色一张主卡**，取代此前「单视图 + 三视图两张」的规则。
> 本文件是唯一权威；SKILL.md / 各 STEP 只引用，不复述。

## 1. 版式（硬规格）

```
┌───────────┬──────────────────────────────────────────┐
│           │                                          │
│  大头照    │        全身三视图（正 / 侧 / 背）          │
│  1/3 宽    │            2/3 宽                        │
│           │                                          │
└───────────┴──────────────────────────────────────────┘
                      16:9 横构图
```

| 项 | 规格 |
|---|---|
| 画幅 | **16:9 横构图**（建议 2048×1152，1K 档 1536×864） |
| 左栏 | **头部特写**（正面、半身以上，脸占主体；发丝、皮肤、妆容清晰可辨） |
| 右栏 | **三个全身像等间距横排：正面 / 侧面 / 背面**，全身完整**包含鞋** |
| 人物一致性 | 四张脸 + 三个身体必须是**同一个人、同一套服装、同一光照** |
| 背景 | 纯净浅灰/纯底，无场景、无光效、无道具 |
| 文字 | **零文字**：不写 FRONT/SIDE/BACK、不写角色名、不加水印、不画分栏线 |
| 画风 | 跟随 STEP 0 选定的风格锁（与本卡其它产物同一套） |

**为什么合成一张**：脸由左栏定、身型服装由右栏定，一张图就够；只有一张参考时视频模型不必纠结「该认哪张脸」，比多张更稳。

## 2. 已验证的 prompt 模板（可直接用）

```text
角色设定图（character sheet），16:9 横构图，纯净浅灰背景，画面上不得出现任何文字、字母、标注、水印。

版式严格分两栏：
左栏占画面宽度 1/3：同一人物的头部特写半身像，脸占画面主体，正面朝向镜头，头发分缝、发丝质感、皮肤质感、妆容清晰，肩部以下裁掉。
右栏占画面宽度 2/3：横排三个人物全身像，等间距排列，依次为正面、侧面、背面；全身完整包含鞋；三人是同一个人的同一套服装，姿态自然站立、双臂自然下垂。

人物设定：<年龄/性别/国籍>，<发型与发色>，<肤色与五官要点>，<表情基调>；身穿<上衣>，<下装>，<鞋>，<配饰>。
服装锁定：<主色 / 材质 / 廓形，逐项写死>；<签名道具或不可改特征>。

整张图统一同一人、同一光照、同一服装；背景一律纯净浅灰；不要分割线，不要拼图边框，不要贴纸，不要任何文字标签。
```

**实测基线（2026-10-30）**：上述模板一次生成即达到「左 1/3 大头照 + 右 2/3 三视图 + 零文字 + 含鞋 + 同一人」。唯一常见偏差：左栏肩膀略进画面（不影响当参考图使用，重抽即可）。

## 3. 档位与兜底

| 场景 | 用哪张 | 原因 |
|---|---|---|
| `balanced` / `quality` | **合成卡本尊** | 实测干净（多主体不复制） |
| `fast` | **单视图正面全身**（临时出一张，`card_variant=single`） | 合成卡含 4 个身体，fast 档必出角色副本 / 版面被印进画面 |
| 合成卡出片出现副本 / 版面污染 | 换单视图重渲同镜（同 prompt、同 seed 优先） | 属参考图形态类污染，改 prompt 无效 |

> 单视图兜底卡**不预先批量生成**，只在档位需要或合成卡出问题时按需出，节点标 `cardVariant=single`。

## 4. 出卡前自检（不合格当场重抽，不要带病进入镜头表）

1. 左栏是**大头照**（不是全身、不是半身带腿）
2. 右栏是**三个完整全身**，前 / 侧 / 背顺序，**看得到鞋**
3. 四张脸是同一个人；服装主色、廓形、鞋一致
4. **画面上没有任何文字、数字、字母、水印**
5. 背景是纯底，没有场景、没有分栏线、没有装饰边框
6. 画风与项目风格锁一致

## 5. 资产命名与元数据

- 节点标题：`角色卡·<角色名>`
- `data.role = "character"`、`data.characterName = <角色名>`
- 变体（换装 / 受伤 / 年龄跨度）另出一张，标题 `角色卡·<角色名>·<状态>`
- 入库由用户点「入库」按钮；跨会话复用走 `asset_list` 拿 `character:` 资产 id
