# 2026-10-29 · 左侧导航与设置页（ComfyUI 自检）

## 1. 信息架构

左侧固定导航（可折叠，宽 196px / 收起 56px）：

```
▣ 画布工作室            «
＋ 新建项目
🏠 首页
▤ 项目
🗂 资产
⚙ 设置
（空白）
v0.1.0            ● 已连接
```

右侧内容区切换四个页面：**首页 / 项目 / 资产 / 设置**。
画布页保持全屏（有自己的顶栏：`⌂` 独立回主页按钮 + 项目名下拉 + 右侧状态/设置），不套侧栏。

## 2. 各页面

| 页面 | 内容 |
|---|---|
| 首页 | hero（新建画布）+ 4 个快捷入口（资产库/图片/视频/分镜脚本）+ 最近项目网格 |
| 项目 | 全部项目卡片（缩略图 图/视频、节点数、视频数、图片数、日期），点卡片进画布 |
| 资产 | 跨项目资产网格（130+ 条），角色/场景/道具筛选，视频卡显示首帧 |
| 设置 | ComfyUI 连接状态、能力自检（逐模板）、数据与存储 |

## 3. 设置页的数据来源：`diagnose` API

宿主新增 `POST /comfy-canvas/api/diagnose`：

1. `GET /system_stats` → 版本、显存、延迟；
2. `GET /queue` → 待跑任务数；
3. 读 `templates/*.json`，从 API 格式里**反推需求**：
   - `class_type` 集合 = 需要的节点
   - `UNETLoader.unet_name` / `CLIPLoader.clip_name` / `VAELoader.vae_name` / `CheckpointLoaderSimple.ckpt_name` = 需要的模型
4. 与 `GET /object_info`（4.6 MB，**60 秒缓存**）比对：节点是否在、模型是否在该 loader 的 options 里（只比 basename，容忍路径前缀）；
5. 探测项目目录可写 + `statfs` 剩余空间。

返回结构：

```json
{
  "comfy": { "ok": true, "version": "0.37.2", "vramTotalGB": 31.8, "queue": 0, "latencyMs": 23 },
  "templates": [{ "id": "h3-r2v", "ok": false, "missingNodes": [], "missingModels": ["…safetensors"] }],
  "summary": { "usable": ["edit"], "broken": ["h3-r2v"] },
  "disk": { "freeGB": 52, "projectsWritable": true, "projectsDir": "C:\\Users\\…\\.dsh\\projects" }
}
```

## 4. 其他新 API

| API | 说明 |
|---|---|
| `settings.get` / `settings.set` | ComfyUI 地址覆盖，存 `~/.dsh/comfy-canvas.settings.json`；`comfyBase()` 优先读它 |
| `asset.listAll` | 跨项目汇总资产（带 projectId/projectName/role），供资产页使用 |
