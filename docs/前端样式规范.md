# 画布前端样式规范（v1）

> 参照 DSH 桌面端（BeeftV）的深色界面：**中性黑灰**、低饱和、圆角统一、间距宽松、字号偏大。
> 所有颜色/圆角/字号/间距必须取自下表，禁止在 CSS 里写裸值。

## 1. 颜色令牌

| 令牌 | 值 | 用途 |
|---|---|---|
| `bg` | `#0A0A0B` | 画布底、页面底（**中性黑，不许带蓝**） |
| `panel` | `#141416` | 顶栏、侧栏、浮层 |
| `panel2` | `#1A1A1D` | 输入框、次级按钮 |
| `border` | `#26262B` | 常规描边 |
| `borderStrong` | `#33333A` | hover / 分栏线 |
| `text` | `#E8E8EC` | 主文字 |
| `dim` | `#93939C` | 次级文字、说明 |
| `accent` | `#4D7CFE` | 主按钮、选中态 |
| `ok` | `#35D07F` | 成功 |
| `bad` | `#FF5F6D` | 失败/危险 |

> 禁止再出现 `#0b0c0f`（旧底色，偏蓝）、`#1a1d23`、`#22262e`、`#343943` 这类散落值。

## 2. 圆角

| 对象 | 半径 |
|---|---|
| 卡片（图片/视频/文本/脚本） | **12px** |
| 按钮 / 下拉 / 输入框 | **8px** |
| 小标签（pill、角标） | 999px（全圆） |
| 浮层/菜单容器 | 12px |

## 3. 字号与行高

| 层级 | 字号 | 行高 | 用途 |
|---|---|---|---|
| 导航项 | **14px / 500** | 20px | 左侧导航（旧版 12px 偏小） |
| 面板标题 | 15px / 600 | 22px | 顶栏标题、卡片名 |
| 正文 | 13px | 20px | 提示词、按钮、表格 |
| 辅助 | 12px | 18px | 角标、分辨率、时间 |
| 说明文字 | 12px / 400，颜色 `dim` | 18px | 空态提示 |

字体族：`system-ui, -apple-system, "Segoe UI", "Microsoft YaHei", sans-serif`。

## 4. 间距刻度

`4 / 8 / 12 / 16 / 24 / 32`（px）。组件内边距优先 8/12，块间距 16，区块之间 24。

| 位置 | 规范 |
|---|---|
| 顶栏内边距 | 10px 14px |
| 卡片内边距 | 12px |
| 卡片之间 | 16px（自动落卡） / 24px（手动排布建议） |
| 面板与画布间距 | 16px |
| 按钮内边距 | 6px 12px |

## 5. 卡片

| 项 | 规范 |
|---|---|
| 圆角 | 12px |
| 描边 | 1px `border`；hover 用 `borderStrong`；选中 2px `accent` |
| 阴影 | hover 才加（`0 12px 30px rgba(0,0,0,.55)`），静止不加 |
| 图片填充 | `object-fit: cover`，不拉伸变形 |
| 角标 | 右上角，12px，`panel` 底 + 80% 透明 |
| 卡片名 | 底部左对齐，13px，超长省略号 |

## 6. 状态色使用

- 生成中：`accent` 描边 + 呼吸动画
- 成功：右上角小圆点 `ok`
- 失败：描边 `bad` + 卡片内一行说明（不弹窗）
- 空态：居中一行 `dim` 文字 + 一个主按钮

## 7. 落地检查清单

- [ ] 页面底色为 `#0A0A0B`，与设置页一致（不再偏蓝）
- [ ] 所有卡片 12px 圆角、按钮 8px
- [ ] 左侧导航 14px，比正文大一号
- [ ] 角标/分辨率 12px 可读
- [ ] 不存在裸写的颜色值（全部走令牌）
- [ ] 自动落卡间距 16px，不重叠
