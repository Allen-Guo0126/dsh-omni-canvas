# dsh-omni-canvas · 视觉与交互规范（v1）

> 目标：深色、克制、工具感。**画面（作品）永远是主体**，UI 只做容器，不与作品争注意力。

---

## 1. 色彩

| Token | 值 | 用途 |
|---|---|---|
| `bg` | `#0b0c0f` | 画布底色 |
| `bg-elev` | `#14161a` | 浮层 / 顶栏 |
| `surface` | `#171a1f` | 菜单、卡片内占位 |
| `surface-2` | `#1a1d23` | 输入框、下拉框 |
| `border` | `#23262c` | 默认描边（1px） |
| `border-strong` | `#343943` | hover 描边 |
| `text` | `#e7e9ee` | 主文字 |
| `text-dim` | `#8b919c` | 次要信息 |
| `accent` | `#4d7cfe` | 选中态、主按钮（**唯一强调色**） |
| `ok` | `#35d07f` | 仅用于连接状态点 |
| `bad` | `#ff5f6d` | 错误 |

规则：
- 一个界面里**强调色只出现一次**（选中的卡片描边 + 浮层主按钮）。
- 按钮不用绿色；绿色只表示「连通」。
- 网格点：`rgba(255,255,255,.055)`，间距 22px。

## 2. 字体与字号

| 角色 | 字号 / 行高 | 字重 |
|---|---|---|
| 正文 / 输入 | 13 / 1.5 | 400 |
| 菜单项 | 12.5 | 400 |
| 次要说明、参数 | 11.5–12 | 400 |
| 分组标题 | 11 | 500，颜色 `text-dim` |

字体栈：`system-ui, -apple-system, "Segoe UI", sans-serif`。

---

## 3. 圆角与阴影

| 元素 | 圆角 | 阴影 |
|---|---|---|
| 卡片 | 12px | `0 10px 26px rgba(0,0,0,.45)` |
| 浮层 / 菜单 | 12px | `0 18px 44px rgba(0,0,0,.6)` |
| 输入框 / 下拉 | 6–8px | 无 |
| 圆形按钮 | 50% | 无 |

选中卡片额外加 `0 0 0 2px rgba(77,124,254,.35)`。

---

## 4. 画布

- 无限画布，点阵背景，滚轮以**指针为中心**缩放（0.2×–2.5×）。
- 空白拖拽 = 平移；单击空白 = 取消选中；**双击空白 = 在指针位置弹出「添加节点」菜单**。
- 右下角缩放控件：`− 100% +`，胶囊样式，半透明背景。
- 左下角显示当前状态（如「点＋图片开始创作」）。

---

## 5. 卡片（节点）

- **卡片只显示画面本身**：无标题栏、无角标、无参数。
- 尺寸：宽度 320，高度按 `生成图宽高比`（无图时按所选画幅）换算。
- 生成中：半透明遮罩 + 「生成中…」/「排队中…」。
- 选中：1px accent 描边 + 外发光。
- 选中时卡片**左右各出现一个圆形 `+`**（20px，距卡片 8px），用于在该侧新建并自动连线。

---

## 6. 参数浮层（Composer）

位置：**紧贴选中卡片正下方 10px**，宽度 470–620，跟随缩放（屏幕坐标计算，非画布坐标）。

结构（自上而下）：

```
[＋ 上传] [▣ 画布参考] [◈ 标记] [✧ 风格]      ← 工具条（chip，11.5px）
┌────────────────────────────────────────┐
│ 可直接文字生图，或上传图片后输入文字指令…   │  ← 文本域（min 56px，可拖高）
└────────────────────────────────────────┘
[模型 ▾] [画幅 ▾] [张数 ▾] [1K/2K ▾] [种子]      ( ↑ )   ← 圆形发送
```

- 发送按钮：**圆形 34px、深灰蓝底、白色 ↑ 图标**，无文字、无绿色。
- 生成中：按钮变 `…` 并禁用，顶栏状态显示「生成中…」。
- 回车发送，Shift+回车换行。
- 浮层内点击不取消选中。

---

## 7. 添加节点菜单

- 触发：双击画布空白处，出现在**指针位置**。
- 宽 246px，两组：`添加节点` / `添加资源`，中间 1px 分隔线。
- 每项：16px 图标 + 文字，行高 30px，hover 背景 `#22262e`。
- 未实现的能力**置灰并保留**（视频、导演台、脚本、文本、音频、上传、从生成历史选择），不隐藏——让用户知道将来会有。
- `NEW` 标签：胶囊，11px，`#1f2a3d` 底 / `#7fb0ff` 字。

---

## 8. 顶栏

`● 项目▾ | ＋项目 重命名 删除 | ＋图片 适应 | … | 状态文字`

- 左侧 8px 圆点：绿=ComfyUI 连通，红=未连接（hover 显示地址/错误）。
- 项目选择用原生下拉（可后续换自定义）。
- 右侧状态文字 11px `text-dim`。

---

## 9. 动效

- hover / 选中：0.15–0.18s `ease`，只动背景、描边、阴影。
- 不做位移弹跳、不做缩放弹跳。
- 卡片拖动跟手（无过渡）。
- 缩放无动画（直接跟随滚轮）。

---

## 10. 禁止项

- ❌ 卡片上放标题栏、尺寸角标、参数
- ❌ 绿色按钮 / 渐变按钮
- ❌ 卡片内多个 icon 堆叠
- ❌ 白色或浅色背景
- ❌ 大面积纯 accent 块（只在描边、按钮、选中小点）
