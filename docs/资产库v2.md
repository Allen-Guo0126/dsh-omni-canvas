## 一、竞品参考（说明：本次无法联网核实）

网络检索当时不可用（搜索接口 402），以下来自我对同类产品的了解，**未做二次核实**，仅作为设计输入，不作为事实依据。

| 产品/形态 | 我记得的特点 | 我借鉴了什么 |
|---|---|---|
| 无限画布类 AI 工具（如 Krea / Recraft 的画布态） | 生成记录自动沉淀成库，可回溯每次生成的多个变体 | **版本组**：同一张卡的第 1/2/3 版聚合，`v1/18` 直接切换 |
| 影视前期工具（如 Runway 的 assets、Kling 的素材库） | 素材按项目/镜头组织，缩略图墙 + 类型筛选 | **分面筛选**：类型 / 角色 / 场次 |
| 分镜流程工具（如 Boords / Storyboarder 类） | 以"场 → 镜"为主线，每镜挂参考图、关键帧、成片 | **流程视图**：按场分组，场内镜头带缩略图 + 该镜参考图 |
| 节点式工具（ComfyUI / Nuke 式） | 产物保留来源链，可追溯到父节点 | **血缘**：父链 / 子链可查 |
| 素材管理（Eagle / Billfish） | 标签、收藏、搜索、拖拽入画布 | **标签 / 收藏 / 搜索 / 拖拽** |
| 系列剧工具 | 按集-场-镜三级组织，能一眼看出哪场还没出片 | **场次计数**（场标题 + 条数） |

## 二、本次真正落地的能力

### 数据模型（向后兼容，旧字段不动）

```
id file kind            // 原有
role                    // character | scene | prop | voice | shot | frame | upscale | edit | other
sceneId sceneTitle      // 归场
rowId shotLabel         // 归镜（脚本卡的行）
parentId rootId         // 血缘
tags[] favorite         // 人工标注
width height durationSec sizeBytes
```

### 接口

| 接口 | 作用 |
|---|---|
| `asset.query` | 过滤（kind/role/scene/favorite/q/nodeId）+ 分面 + 分页 + 版本组 |
| `asset.update` | 改名 / 改角色 / 标签 / 收藏 |
| `asset.lineage` | 父链 + 子链 |
| `asset.scenes` | 按场分组的镜头流程（含该镜参考图） |
| `asset.stats` | 统计 |
| `asset.migrate` | 幂等补齐旧资产元数据 |

### 面板（画布右侧「资产库」）

```
资产库 · 114            [▦ 网格] [☰ 流程] [✕]
[搜索提示词/镜号/场次/标签…]  [★]
类型  全部 图片 视频 音频
角色  全部 角色 场景 道具 镜头 音色
场次  场景1·老街 42 | 场景2·客厅 11 | 未归场 61
─────────────────────────────────
┌────┐ 每张卡：缩略图 / 角标(角色·镜号·v1/18·★)
│ ▶  │ 悬停操作：★收藏 ⌘血缘 ◎定位到画布 ↓下载 ✕删除
└────┘ 可拖拽到画布任意位置
```

流程视图：`场标题(条数)` → 横向镜头带，每镜显示缩略图、镜号、时长、**该镜用到的参考图**（最多 4 张）。
