## 一、它把「分镜」定义成一门有依据的工种，不是画面描述

它的分镜单位是一颗镜头（`## SHOT-...`），每镜必须填满这些字段：

| 字段 | 要求 |
|---|---|
| **职责** | 这一镜唯一负责的戏剧功能（信息 / 权力 / 情绪 / 空间 / 节奏 之一） |
| **来源** | 以剧本里真实存在的场景 ID 开头，可带短引文；多个用 `、` 连写 |
| **时长** | 由声音事件推算，不从字数折算 |
| **景别 / 水平角度 / 机位高度 / 焦段意图** | **四件事分开写**，不能只写「俯拍」当四件都定了 |
| **运镜** | 逐镜写「行为 + 为什么」，固定机位也要写理由 |
| **起点 → 唯一动作 → 终点** | 起点是已接受边界；唯一动作是一条可见状态链（交接要写接触与落点）；终点逐项接住位置、双手、持物 |
| **声音** | 台词估时依据、开口前停顿、说完后的反应、并行动作 |

**关键洞察（我原来完全没有的）**：

1. **「塞多了不会被删，会被压扁」**——视频模型拿到 6 个连续动作，3 次都「做完」了，但从第三件起每件只有半秒；不是丢动作，是压到看不清。所以要在分镜阶段就数「观众要看清几件事」。
2. **镜长由声音事件 + 目标平均镜长推出**（`target_avg_shot_seconds`），目标平均是整场目标不是每镜配额；插入镜可以不到 1 秒，一句要落地的台词可以 4–5 秒。
3. **水平角度 ≠ 机位高度**：写「俯拍」其实常常想要的是「从她背后越过肩膀」（那是水平角度）。下游按字面给俯拍，权力关系当场反转。竖屏里高度变化「更贵」，先看水平角度和距离能不能承担。
4. **冻结关键帧只投影起点，尾帧可选**：写完再回填三条依据（视觉依据 / 图片提示词项 / 输入参考图），三轴共用同一张画面清单，不能互相矛盾。

## 二、镜头切换：它有明确的「切点合法性」判据

这是用户说「镜头切换不够好」的病根——我们基本只靠景别差异，它有一整套：

| 规则 | 内容 |
|---|---|
| **切点必须带来可见变化** | 已经决定切镜后，新镜必须在**景别 / 水平角度 / 人物关系**里至少改变一项；相邻两镜三者都没变 → 观众读到的是跳切或穿帮，这个切点没有存在理由 |
| **不切镜也是选择** | 压力累积、人物在同一构图里改变距离、观众被迫看着不肯变的画面，都是有效理由 |
| **工作景别** | 一场通常比真正要演的景别先开宽一档，第二镜落到本场工作景别，之后多数切镜在这一档上下「一格」来回；宽景和特写是**离开**工作景别的标记事件，用过就回来 |
| **轴线与正反打** | 两人交锋保持摄影机在同一轴线工作侧；越轴后要「重新记账」（重新写方位） |
| **对白场默认切法** | 一句台词一镜；重要一句落下时**切到听的人**；交锋用正反打；先交代再落到中/中近景；**只在一句话需要落地时切特写**；无台词无动作的空镜删掉；插入镜（手机屏/手/戒指/证件）是最便宜的节奏工具 |
| **相连边界（CON-01）** | 本镜已接受的结束边界必须与下一镜已接受的开始边界一致；不一致必须声明修订或过渡，**不能用摄影机描述掩盖边界冲突** |
| **反模式清单** | 情绪升级=景别收紧（条件反射）；相邻两镜同景别同角度；套话式布光替代空间锚点；一镜跨地点无省略依据 |

还有一条对我们特别重要：**建立镜头要自己挣到位置**。竖屏快节奏里默认「地理在动作内部到达」，不要开场先给一个空景全景。

## 三、剧本改写（`short-drama-write` + `script-craft` 48KB）

核心不是文笔，而是**每场必须改变状态**：

- 每场改变**信息 / 权力 / 关系 / 情绪 / 物理状态 / 风险**之一；无变化的场删掉或合并
- 对白必须在**争取、回避、试探、逼迫、重新定义关系**；每句都要能转成演员的一个动作或表情，转不成的删掉
- **能演的不说**：`[VO]`、内心独白、痛点交代有专门章节约束
- 自己写的初稿要读一遍删掉不承担动作或冲突的句子；**创作者原文优先**，「去 AI 味」是定点修订，不抹平个性
- 装不下的对白不加速，而是**拆到说话者与听者的几个镜头**，声音连续、画面切换、语速不变
- 交稿前静默反查：观众能否接收到本集承诺、行动是否有因果、有没有为了填模板硬加班、有没有为了显刻度加一句「理解了我的愤怒」
- 它有 Python 时长估算脚本（`duration_estimate.py`），台词时长按实际读法估，不数字符

## 四、我们现在的差距（对照表）

| 维度 | 我们（story-short-generator / 画布分镜卡） | 它 | 差距性质 |
|---|---|---|---|
| 镜头表字段 | 镜号 / 时长 / 景别 / 运镜 / 画面描述 / 光影 / 台词 / 音效 / 资产 | 职责 / 来源 / 起点→唯一动作→终点 / 四维机位 / 声音依据 | **缺「职责」「起点终点」「切点理由」**，导致镜头像剧本句子的改写 |
| 切点判据 | 无机械判据，靠模型自觉 | 三要素至少变一项，否则禁止切 | **可以用代码检查**（这是最值得做的）|
| 镜长 | 按默认 4–10 秒选 | 按声音事件 + 目标平均镜长推 | 需要节奏档案 + 估时 |
| 景别/角度 | 只有一个「景别」下拉 | 景别 / 水平角度 / 机位高度 / 焦段 四栏 | 我们缺三栏 |
| 连续性 | 有「续接」列 + 血缘徽标 | CON-01 边界一致性 + 场景站位（锚点/轴线/working side） | 我们只有技术续接，没有**空间连续性** |
| 自检 | 镜头表自检门（较泛） | 机械检查（ID 解析、名称反查）+ 语义审查分离 | 我们可以把机械那层做进插件 |
| 剧本改写 | 靠 prompt 提示「去 AI 味」 | 有具体判据（每句可转动作、每场必须变状态） | 需要把判据写进自检 |

## 五、建议的改进（按性价比排序）

### P0｜画布「分镜自检」按钮（机械层，可立刻做、可验证）
对当前脚本卡逐行检查并给出可点击的问题列表：

1. 相邻两镜：`景别 + 运镜 + 人物关系` 三者完全相同 → **「这个切点没有存在理由」**
2. 每镜缺「职责」或「起点/终点」→ 提示补
3. 台词字数 × 语速 > 该镜时长 → 「台词装不下，拆到听者镜头或延长」
4. 同一场景内人物位置/朝向在两镜间无理由反转 → 「轴线/站位冲突」
5. 同场次所有镜都是特写 → 「没有工作景别，全程收紧没有余量」
6. 空镜（无台词、无动作、无道具变化）→ 建议删

### P1｜镜头表升级为「戏剧字段版」
在画布脚本卡增加三列：**职责**、**起点→终点**、**切点理由**；并把「景别」拆成「景别 / 水平角度 / 机位高度」。
（列变多会影响卡片宽度，建议做成可折叠「详细模式」）

### P2｜剧本改写自检门
把 `short-drama-write` 的判据做成一次「剧本体检」：每场是否改变状态、每句台词能否转成动作、是否有可演省略的地方。

### P3｜节奏档案
项目设置加 `target_avg_shot_seconds` 与 `close_shot_share_min`，分镜卡按声音事件算镜长、按占比校验近景。

## 六、我读完后最想改的三件事（一句话版）

1. **切点必须有变化**——可以写成代码检查，收益最大。
2. **镜长从声音来**——不再按 4–10 秒猜。
3. **镜头要有职责和起终点**——否则永远是「把剧本句子改写成画面描述」。
