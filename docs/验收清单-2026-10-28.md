# 今晚补齐的功能 · 验收清单

> 验证时间：2026-10-28 深夜
> 插件：`@local/dsh-omni-canvas`（`E:\Allen\plugins\dsh-omni-canvas`，已通过 junction 直连 profile）
> **重启 DSH 一次**（本轮改的是宿主）后按下面逐条点。

---

## 1. 生成队列（串行 + 取消）

**做了什么**

- 所有图片/视频任务进入**串行队列**，一次只跑一个，不再并发抢 GPU；
- 顶栏显示 `生成中 N · 排队 M`；
- 排队中的卡片显示「排队中…」，正在跑的显示「生成中… + 取消」按钮；
- 新增 API `job.list` / `job.cancel`，新增工具 `cnv_job_list` / `cnv_job_cancel`。

**端到端测试（宿主）**

```
queue before cancel: {running: ed0ea32b, queue: [{id: 7f5622a5, position: 1}]}
cancel result:       {ok: true, status: "canceled"}
queue after cancel:  {running: ed0ea32b, queue: []}
B status:            canceled          ✅
```

**验收动作**：连点两次生成 → 顶栏应出现「生成中 1 · 排队 1」→ 点排队卡的取消 → 消失。

## 2. 视频拼接 `cnv_concat`

**做了什么**

- 按脚本卡行顺序自动取片（也可传 `nodeIds` 指定顺序）；
- ffmpeg 通过 **stdout 管道**输出、由 Node 写入项目（绕开本机对子进程写项目目录的限制）；
- 产物写回画布为一个视频节点 + 进资产库。

**端到端测试**

```
concat: {nodeId: n-c6b96942, file: media/bc7e0710….mp4, clips: 15}
ffprobe: 1280x704, h264+aac, 98.8s, 13.9 MB      ✅
```

**验收动作**：对话里说「把成片拼一次」，或让我调 `cnv_concat`。

## 3. 脚本批量生成不再重复堆卡

**做了什么**

- 每张生成的卡片记 `rowId`；
- 同一行已有卡片 → **跳过**（返回 `skipped`）；
- `run=true` 且卡片已存在 → **直接提交那张卡**，不新建。

**测试**

```
dedupe: created 0 / skipped 1                ✅
run=true（已有卡）: running {id: 6fa9be4b}    ✅
```

**做了什么**

- 行尾新增 `⧉ 复制`、`✕ 删除`；
- 复制会连资产绑定一起复制。

## 5. 重做（Ctrl+Shift+Z）

**做了什么**

- `Ctrl+Z` 撤销、`Ctrl+Shift+Z` 重做；
- 撤销时把当前状态压进 redo 栈，新操作清空 redo 栈。

**DOM 测试**

```
新增节点: 5 → Ctrl+Z: 4 → Ctrl+Shift+Z: 5   ✅
```

## 8. 顺带修的老问题

| 问题 | 修复 |
|---|---|
| 删卡片删不掉 | rev 冲突时自动用最新 rev 重试一次 |
| 视频卡比图片卡小 | 卡片宽度统一 320，高度按素材比例，最小 200 |
| 脚本卡不能拖动 | 拖标题栏可移动 |
| 点脚本卡弹出提示词浮层 | 脚本卡不再显示浮层 |
| 添加菜单点空白关不掉 | 点空白 / Esc 关闭 |
| 参考卡被投影进视频 | 用左 1/3 裁切的单视图做参考 |
