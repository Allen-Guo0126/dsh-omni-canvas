# 提示词审查清单（G19 强制门）

> 用法：任何一批 H3 提示词在提交生成前，逐段、逐刀过这张表。
> 任一条不通过 → 不许生成。审查结果归档到画布「审查报告」卡。

## A. 台词（逐字）
- [ ] 与剧本台词表**逐字**一致（含标点、`——`、`……`、`C9` 空格）
- [ ] 没有漏句、重复句、串句
- [ ] 跨刀句子：前刀末尾 `<scenetrans>` + "audio continues seamlessly across the cut"；后刀开头 `continues the same sentence without pause`
- [ ] 两刀拼起来是完整一句

## B. 说话人（G15）
- [ ] 每句台词的说话人**在该刀画面内**且开口
- [ ] 若为画外音：该刀画面里**没有正脸人物**（只有插入镜/空镜/后脑）
- [ ] 非说话人写明 `lips remain completely closed`

## C. 朝向（G16）
- [ ] 双人镜写了 `face each other`
- [ ] 写了 `bodies angled about 45 degrees to the lens`
- [ ] 写了 `neither looks into the lens`
- [ ] 单人镜写了“朝向画外的对手”，不是“面向镜头”

## D. 调度（对手戏）
- [ ] 喊人/拦住/追人：被喊的人背对或侧对，对方转向他
- [ ] 对峙：两人正对（侧面 90° 或各偏 45°）
- [ ] 没有“两人面对面站着喊请留步”这种逻辑反了的调度

## E. 动作链（G18）
- [ ] 每刀动作能连起来：起点 → 触发 → 终点
- [ ] 终点在画面内（除非该刀结束）
- [ ] 没有“正走出画面”+“停下/回头”
- [ ] 没有“背对镜头”+“表情”
- [ ] 没有“已坐下”+“站起身”（同一刀）
- [ ] 没有“说完转身走”+“继续说话”

## F. 时长与容量（G11）
- [ ] 每刀 ≥3.0 秒
- [ ] 每刀台词字数 ÷ 4.0 + 0.5 ≤ 刀长 − 0.7
- [ ] 跨刀处的停顿没有吃掉台词

## G. 连续性与道具
- [ ] 同一物件前后一致（石子、襁褓、工牌、准考证）
- [ ] 灯态前后一致（未亮 → 某刀亮 → 之后保持亮）
- [ ] 巷口/门/桌的位置没有漂
- [ ] 人物数量与段首声明一致

## H. 光
- [ ] 只写“光沿用场景图”，没有 K 值/亮度区间/光比
- [ ] 没有“近乎全黑 / 天光已退 / 只剩剪影 / 纯黑”这类压暗词
- [ ] 有“人脸始终可辨”这类下限（如场景本身偏暗）

## I. 画面文字
- [ ] 有禁字幕/禁文字条款
- [ ] 场景里可能带字的物件（招牌、匾额、对联、年画）已确认或已处理

## J. 长度
- [ ] 每段 900–1400 字符；超过 2000 说明在重述图片信息
- [ ] subject_definitions ≤ 3 行，只写“图几是谁、完全照它”

---

## 输出格式

```
段号 | 不通过项 | 依据（引用原文） | 改法（一句话）
```

最后给结论：**可以生成** / **需修改后再生成**。
