# 提示词审查清单（G13 执行清单）

> 用法：任何一批 H3 提示词在提交生成前，逐段、逐刀过这张表。
> **任一条不通过 → 不许生成。** 审查者不能是写这批提示词的人。
> 结果归档到画布「审查报告」卡。规则依据见 `场级双基准与门禁规范.md`（v3）。

## A. 台词（G3 / §15）
- [ ] 与剧本卡台词**逐字**一致（含标点、`——`、`……`、`C9` 前后的空格）
- [ ] 没有漏句、重复句、串句
- [ ] 跨刀句子：前刀末尾 `<scenetrans>` + `audio continues seamlessly across the cut`；后刀开头 `continues the same sentence without pause`
- [ ] 两刀拼起来是完整一句
- [ ] 字数 ÷ 4.0 + 0.5×句数 ≤ 刀长 − 0.7

## B. 说话人（G6）
- [ ] 每句台词的说话人**在该刀画面内**且开口
- [ ] 若为画外音：该刀画面里**没有正脸人物**（只有插入镜 / 空镜 / 后脑）
- [ ] 非说话人写明 `lips remain completely closed`

## C. 朝向（G7）
- [ ] 双人镜写了 `face each other`
- [ ] 写了 `bodies angled about 45 degrees to the lens`
- [ ] 写了 `neither looks into the lens`
- [ ] 单人镜写「朝向画外的对手」，不是 `facing the lens`

## D. 调度（§6.4）
- [ ] 喊人 / 拦住 / 追人：被喊的人背对或侧对，对方转向他
- [ ] 对峙：两人正对（侧面 90° 或各偏 45°）
- [ ] 没有「两人面对面站着喊请留步」这种反逻辑调度

## E. 动作链（G8）
- [ ] 每刀动作能连起来：起点 → 触发 → 终点
- [ ] 终点在画面内（除非该刀结束）
- [ ] 没有「正走出画面」+「停下 / 回头」
- [ ] 没有「背对镜头」+「表情」
- [ ] 没有「已坐下」+「站起身」（同一刀）
- [ ] 没有「说完转身走」+「继续说话」

## F. 光（G1）
- [ ] 只写「光沿用场景图」，没有 K 值 / 亮度区间 / 光比
- [ ] 没有「近乎全黑 / 天光已退 / 只剩剪影 / 纯黑 / 压暗」
- [ ] 有「人脸始终可辨」这类下限
- [ ] 光的状态变化（灯亮 / 烛灭）指定了发生的那一刀

## G. 连续性与道具
- [ ] 同一物件前后一致（石子、襁褓、工牌、准考证）
- [ ] 灯态前后一致（未亮 → 某刀亮 → 之后保持亮）
- [ ] 巷口 / 门 / 桌的位置没有漂
- [ ] 人数与段首声明一致

## H. 画面文字（§14，本片无字幕）
- [ ] 有 `NO ON-SCREEN TEXT OF ANY KIND` 否证句
- [ ] 场景里可能带字的物件（招牌、匾额、对联、年画）已确认或已处理

## I. 长度（G10）
- [ ] 每段 900–1400 字符（>2000 = 在重述图片）
- [ ] subject_definitions ≤3 行，只写「图几是谁、完全照它」

## J. 门与格式
- [ ] 六段齐全且顺序正确（subject_definitions → summary → retention_analysis → detailed_description → overall_soundscape → non_diegetic_music）
- [ ] 切点句为 `At 00:0X.XXX, the camera cuts to …`
- [ ] 每刀 ≥3.0 秒

---

## 输出格式

```
段号 | 不通过项 | 依据（引用原文一句） | 改法（一句话）
```

结论：**可以生成** / **需修改后再生成**。
